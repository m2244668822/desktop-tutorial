# 工程與安全性標準 (Engineering & Security Standards)

## 代碼品質
1. **顯性優於隱性**：優先使用組合與委託，而非繼承。
2. **無死角測試**：新功能需附帶單元測試；Bug 修復需附帶回歸測試。
3. **類型系統**：嚴格 TypeScript/Python 類型標註，禁止 `any` 或 `ignore`。

## 安全性規範
1. **敏感數據**：嚴禁硬編碼。使用 `.env`。
2. **權限最小化**：僅請求執行任務所需的最小權限。
3. **審計追蹤**：所有高風險操作（如修改系統配置）必須留下日誌。

## Windows 相容性
1. **編碼**：讀寫檔案時明確指定 `encoding='utf-8'` 或符合 Windows 期待。
2. **路徑**：使用 `pathlib` 處理跨平台路徑問題。
