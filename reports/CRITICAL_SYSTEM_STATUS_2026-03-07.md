## 🔍 根本原因分析

### **主要原因: 系統級內存泄漏**

1. **Ollama 進程**: 即使終止也無法完全釋放內存
2. **操作系統緩存**: 2090MB 壓縮內存未被 macOS 有效回收
3. **系統服務**: 其他後台服務占用大量內存

### **觸發因素**

- Phi 模型推理需要 50-70 秒，此期間內存不斷增長
- Ollama 試圖加載整個模型到 RAM
- 8GB 系統無法同時支持 Ollama + 其他應用

## 🔧 推薦解決方案

### **方案 1: 系統重啟 (強烈推薦) ⭐⭐⭐**

```bash
# 立即執行系統重啟以清空所有內存
sudo shutdown -r now

# 或
System Preferences → Restart Now
```

**預期效果**:

- ✅ 內存完全清空 (從 99.8% 恢復到 30-40%)
- ✅ 所有僵化進程終止
- ✅ Ollama 服務可恢復正常
- ⏱️ 預計時間: 1-2 分鐘

**術後檢查**:

```bash
# 重啟後執行
top -l 1 | grep PhysMem  # 應該顯示 40-50% 使用率
ollama serve &           # 應該能正常啟動
curl http://localhost:11434/api/tags  # 應該返回模型列表
```

---

### **方案 2: 無法重啟時的應急措施**

1. **關閉所有非必要應用**

   ```bash
   # 關閉 Xcode, Chrome, IDE 等重型應用
   killall Chrome
   killall Code
   ```

2. **強制回收內存**

   ```bash
   # 清空 macOS 緩存
   purge
   # 或
   sudo purge
   ```

3. **終止並清理 Ollama**

   ```bash
   killall -9 ollama
   rm -rf ~/.ollama/gpu-layers/*  # 清理 GPU 層緩存
   ```

4. **啟用 swap (僅作最後手段)**
   ```bash
   # 理論上可救急，但會導致性能嚴重下降
   # 不推薦在 Phi 模型下使用
   ```

### **方案 3: 長期改善方案**
