## 2. 問題根因分析

### 問題：智能體無法正確回報 NVAPI 狀態

**原因**: [`desktop_chat_app.py`](desktop_chat_app.py:561) 中的 `_api_health()` 方法只檢查 `OPENAI_API_KEY`，而實際金鑰存放在 `NVAPI_API_KEY`。

**修復內容**:

1. 修改 [`_api_health()`](desktop_chat_app.py:551) 方法優先檢查 `NVAPI_API_KEY`
2. 新增 `key_source` 欄位以識別使用的 API 金鑰來源
3. 更新所有相關報告方法以正確顯示 NVAPI 狀態
