# NVIDIA API 優化狀態報告

> 安全修訂：2026-08-24

## 狀態

- NVIDIA 是崔佛的控制核心，供應商路由由 `core/provider_registry.py` 管理。
- 真實憑證不得寫入報告、程式碼或 `.env.example`。
- macOS 從 Keychain 服務 `trevor.providers` 讀取憑證；OCI 從 systemd credentials 讀取。
- `OPENAI_API_KEY` 不作為 NVIDIA 的後備憑證。
- Provider 公開狀態只呈現模型、健康度、免費配額與熔斷狀態。

## 安全處置

- 本報告過去曾包含 NVIDIA 憑證形態字串，現已移除。
- 該憑證應視為已洩漏並在 NVIDIA 控制台輪替；舊值不得繼續部署。
- CI 執行 `python tools/scan_secrets.py`，任何秘密 finding 都阻擋合併。

## 驗證

```bash
python tools/scan_secrets.py
python -m unittest tests.test_provider_registry tests.test_provider_credentials
```
