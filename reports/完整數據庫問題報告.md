## 📋 問題摘要

系統聲稱可以訪問 **1,324 條 ChatGPT 對話**（完整歷史記錄），但實際上由於代碼中的硬編碼限制，只加載了前 **100 條**，導致 **92.4% 的對話記錄無法被訪問**。

---

## 🔍 問題診斷過程

### 1. 初始症狀識別

用戶提出："完整數據庫問題"

系統表現：

- 統計顯示：1,324 條 ChatGPT 對話可用
- 實際加載：只有 100 條可訪問
- 用戶混淆：聲稱"完整記憶"但無法訪問大部分數據

### 2. 技術調查

**診斷工具**：

- `diagnose_database.py` - 數據庫完整性檢查
- `diagnose_api_usage.py` - API 實際行為分析

**調查結果**：

| 指標           | 數據庫實際值 | API 加載值 | 差距           |
| -------------- | ------------ | ---------- | -------------- |
| ChatGPT 對話數 | 1,324 條     | 100 條     | 1,224 條未加載 |
| 總消息節點     | 16,478 個    | ~1,200 個  | 92.7% 缺失     |
| 加載比例       | 100%         | 7.6%       | -92.4%         |

### 3. 根本原因定位

**文件**: `tools/local_memory_api.py`  
**方法**: `get_all_conversations()`  
**問題代碼** (Line 131):

```python
for conv in conversations[:100]:  # ❌ 硬編碼限制
    standardized = self._standardize_chatgpt_conversation(conv)
    if standardized:
        all_conversations.append(standardized)
```

**原因分析**：

- 為了性能優化而添加的 `[:100]` 切片
- 沒有提供用戶可控的參數
- 沒有文檔說明這個限制
- 統計資訊與實際行為不一致

---

## 💡 解決方案

### 設計原則

1. **靈活性**: 讓用戶選擇加載策略
2. **性能平衡**: 默認保持性能，可選完整加載
3. **透明度**: 清晰顯示實際加載數量
4. **向後兼容**: 不破壞現有代碼

### 實施方案

#### 修改 1: 添加 `chatgpt_limit` 參數

```python
class LocalMemoryAPI:
    def __init__(self, base_dir: str = "...", chatgpt_limit: int = None):
        """
        初始化本地記憶 API

        Args:
            base_dir: 基礎目錄
            chatgpt_limit: ChatGPT 對話加載限制
                          - None: 加載全部（1,324 條）
                          - 0: 不加載 ChatGPT 對話
                          - >0: 加載前 N 條
        """
        self.chatgpt_limit = chatgpt_limit
```

#### 修改 2: 智能加載邏輯

```python
# 根據 chatgpt_limit 決定加載數量
if self.chatgpt_limit is None:
    # 加載全部
    conversations_to_load = conversations
    print(f"  📊 加載全部 {total_available} 條 ChatGPT 對話...")
elif self.chatgpt_limit == 0:
    # 跳過加載
    return
else:
    # 加載限制數量
    conversations_to_load = conversations[:self.chatgpt_limit]
    print(f"  📊 加載前 {self.chatgpt_limit} 條 ChatGPT 對話（共 {total_available} 條）...")
```

#### 修改 3: CLI 選項

```bash
# 默認加載（100 條，快速）
python3 tools/local_memory_api.py --summary

# 完整加載（1,324 條）
python3 tools/local_memory_api.py --summary --full

# 自定義數量
python3 tools/local_memory_api.py --summary --chatgpt-limit 500
```
