## 效能判斷

先前慢的主因不是單純網路。已觀察到：

| 層級             | 判斷                                    |
| ---------------- | --------------------------------------- |
| 前端頁面載入     | 很快，約毫秒到 0.03s 級                 |
| 外網連線         | 先前測試約 0.3s，非主要瓶頸             |
| 雲端模型回覆     | 通常約 1.5s 到 3s                       |
| 本機後端前後處理 | 會受背景任務、DB、輪詢、資源壓力影響    |
| 背景任務         | 仍有 throughput/autofill 與學習任務在跑 |

## 風險與注意

1. `/status` 已遇到後端限流，短期不要連續手動刷新。
2. 任務資料已有 4257 筆，歷史失敗累積 169 筆，後續可做資料庫/任務表清理或歸檔。
3. 歷史對話資料中可能包含私人連結、token 或敏感資訊；本報告沒有複製原始敏感內容。
4. 若使用者仍看到舊 UI，應使用 cache-busting URL 或硬重新整理：`Cmd + Shift + R`。
