### 2. 搜索自動擴展

**目的**: 智能擴展搜索範圍以獲得更好的結果

**實現**:

- 修改 `search_conversations()` 方法
- 新參數：`auto_expand=True`（默認開啟）
- 觸發條件：結果少於 `limit/2` 時自動擴展
- 擴展策略：臨時加載完整 ChatGPT 數據庫（1,324條）

**工作流程**:

```
1. 首次搜索（默認100條ChatGPT數據）
   ↓
2. 評估結果數量
   ↓
3. 如果結果 < limit/2 → 自動擴展
   ↓
4. 臨時加載完整1,324條數據
   ↓
5. 重新搜索
   ↓
6. 返回擴展後結果
```

**實際案例**:

```
搜索 "履歷" (limit=10):
  - 默認加載：找到 2 條
  - 自動擴展：找到 10 條 ✅

擴展後提升: 400%
```

**性能影響**:

- 擴展時間：+1.5 秒（僅在需要時觸發）
- 緩存後：~0.16 ms

### 3. 智能緩存策略

**目的**: 多層緩存提升性能和靈活性

**實現架構**:

```python
_cache_layers = {
    'full': ...,       # 完整數據緩存 (5分鐘)
    'paginated': {...},# 分頁數據緩存 (10分鐘)
    'search': {...}    # 搜索結果緩存 (3分鐘)
}

_cache_stats = {
    'hits': 0,         # 命中次數
    'misses': 0,       # 未命中次數
    'last_clear': ...  # 最後清除時間
}
```

**新增方法**:

1. **get_cache_stats()** - 獲取緩存統計

   ```python
   {
     'hits': 2,
     'misses': 3,
     'hit_rate': '40.0%',
     'cached_items': {
       'full': 1,
       'paginated': 2,
       'search': 1
     }
   }
   ```

2. **clear_cache(type)** - 選擇性清除緩存
   - `'all'` - 清除所有
   - `'full'` - 清除完整數據
   - `'paginated'` - 清除分頁數據
   - `'search'` - 清除搜索結果

**性能提升**:

- 分頁查詢：93% 性能提升（緩存命中時）
- 搜索操作：90% 性能提升（緩存命中時）
- 測試命中率：28.6%（初始階段，使用中會提升）

**CLI 使用**:

```bash
# 查看緩存統計
python3 tools/local_memory_api.py --cache-stats

# 清除搜索緩存
python3 tools/local_memory_api.py --clear-cache search

# 清除所有緩存
python3 tools/local_memory_api.py --clear-cache all
```
