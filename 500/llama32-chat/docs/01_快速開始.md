# 🤖 多智能體 AI 協作系統

**一個強大的自主決策 AI 系統，具有故障轉移、智能選擇和任務管理功能。**

✨ **最新更新 (2026-02-28)**: 全面更新命令路徑、修復 BUG、增強文檔完整性！

## 🎯 核心特性

- 🧠 **中樞神經系統** - 自主決策和故障轉移
- 🤖 **5 個 AI 模型** - Ollama（本地）、Gemini、Claude、OpenAI、xAI
- 📋 **任務系統** - 優先級排程和自動重試
- 📊 **實時監控** - 系統狀態和性能追踪
- 🎪 **圓桌討論** - 多 AI 互動對話（含用戶參與模式）
- 🔗 **多智能體協作** - 消息驅動的通信架構
- 💬 **RAG 檢索** - 對話內容的向量搜索
- 📥 **ChatGPT 導入** - 本地化您的 ChatGPT 對話


```bash

```

- **創意任務**：Claude > Gemini > OpenAI
- **分析任務**：Claude > OpenAI > Gemini
- **程式碼**：OpenAI > Claude > Ollama
- **快速回應**：Ollama > Gemini
- **免費使用**：Ollama（完全免費）> Gemini（大量額度）> Claude（$5/月）

## ❓ 常見問題

**Q: 如何添加新任務？**  
A: 編輯 `tasks/tasks.json` 並運行 `python core/chat.py --tasks`

**Q: 如何使用本地模型避免 API 成本？**  
A: 安裝 Ollama，系統會優先選擇本地模型

**Q: 如何導入我的 ChatGPT 對話？**  
A: 從 ChatGPT 官網導出，運行 `python core/chatgpt_localizer.py -f file.json`

**Q: 模型失敗怎麼辦？**  
A: 中樞神經會自動切換到備用模型，無需人工干預

**Q: 如何查看系統狀態？**  
A: 運行 `python core/monitor.py` 查看實時面板
