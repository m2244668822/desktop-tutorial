# 功能介紹

## 📋 核心功能清單

### 1. 多模型 AI 協作

- **支援 5 個 AI 模型**
  - Ollama（本地模型）
  - Google Gemini
  - Anthropic Claude
  - OpenAI GPT
  - xAI Grok
- **智能模型選擇**
  - 根據任務類型自動選擇最佳模型
  - 創意任務：Claude > Gemini > OpenAI
  - 分析任務：Claude > OpenAI > Gemini
  - 程式碼：OpenAI > Claude > Ollama
  - 快速回應：Ollama > Gemini

### 2. 中樞神經系統

- **自主決策引擎**（`autonomous_agent.py`）
  - 智能選擇模型
  - 自動故障轉移
  - 性能監控與追踪
  - 協調多智能體
  - 動態決策調整

- **神經網絡架構**
  - 6 層神經網絡（輸入層、語義層、上下文層、情感層、決策層、輸出層）
  - 32 個神經元
  - 多維敏感度分析（5 維）
  - 邊界條件檢測
  - 異常檢測機制

### 3. 任務管理系統

- **任務排程**
  - 優先級排程
  - 自動重試機制
  - 失敗恢復
  - 任務歷史記錄

- **任務監控**
  - 實時任務狀態查看
  - 執行進度追踪
  - 性能統計

### 4. 智能體協作框架

- **消息驅動架構**
  - 消息代理（MessageBroker）
  - 事件系統（EventType）
  - 智能體註冊表（AgentRegistry）

- **智能體類型**
  - 基礎智能體（agent.py）
  - 自主決策智能體（autonomous_agent.py）
  - 代碼更新智能體（code_updater_agent.py）
  - 可擴展的自定義智能體

### 5. RAG 檢索增強

- **對話檢索**
  - 向量化搜索
  - 相似度匹配
  - 上下文增強
- **存儲支援**
  - ChromaDB（向量數據庫）
  - 本地 JSON 存儲
  - 記憶管理

### 6. ChatGPT 數據導入

- **數據轉換**
  - OpenAI 對話格式導入
  - 自動格式轉換
  - 去重和清理
- **導入狀態**
  - 1,324 個對話已導入
  - 15,154 條消息
  - 100% 完整性驗證

### 7. 圓桌討論模式

- **多 AI 協作**
  - 多個模型輪流討論
  - 綜合不同觀點
  - 用戶參與模式

### 8. 實時監控

- **系統監控**（`monitor.py`）
  - 模型性能統計
  - 故障日誌和警報
  - 對話記錄統計
  - 響應時間追踪
  - API 使用成本

- **健康檢查**
  - 模型可用性檢查
  - 連接狀態監測
  - 自動修復機制

## 🎮 使用模式

> **📌 注意**：以下命令適用於在 `500/llama32-chat` 目錄中運行。你也可以從根目錄使用 `python tools/chat_client.py`。

### 基本對話

```bash
python core/chat.py "你的問題"
```

### 互動模式

```bash
python core/chat.py --interactive
```

### 指定模型

```bash
python core/chat.py --model claude "你的問題"
```

### 圓桌討論

```bash
python core/chat.py "討論主題" --round-table ollama openai gemini
```

### 用戶參與討論

```bash
python core/chat.py "主題" -urt claude gemini
```

### RAG 檢索

```bash
python core/chat.py "關鍵詞" --rag --rag-topk 5
```

### 任務管理

```bash
python core/chat.py --tasks           # 執行所有待處理任務
python core/chat.py --monitor-tasks   # 查看任務狀態
```

### 系統監控

```bash
python core/monitor.py                # 系統監控面板
python core/chat.py --model-stats     # 模型統計
python core/chat.py --health-check    # 健康檢查
```

### ChatGPT 數據管理

```bash
python core/chatgpt_localizer.py -f conversations.json    # 導入對話
python core/chatgpt_test.py                              # 驗證完整性
```

### 從根目錄使用（推薦）

```bash
# 簡易版本
python demos/easy_chat.py

# 完整功能版本
python tools/chat_client.py
```

## 🔧 高級功能

### 1. 故障轉移

系統在模型失敗時自動切換到備用模型：

- 記錄失敗次數
- 達到門檻後標記冷卻
- 自動選擇備用模型
- 無需人工干預

### 2. 性能追踪

追踪每個模型的表現：

- 成功率統計
- 響應時間記錄
- 使用成本計算
- 錯誤日誌保存

### 3. 智能決策

根據多維度因素選擇模型：

- 任務類型
- 模型狀態
- 歷史性能
- 用戶偏好

### 4. 記憶管理

管理對話歷史和上下文：

- 對話持久化
- 向量索引
- 相似度檢索
- 記憶摘要
