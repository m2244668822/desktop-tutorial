## 📖 概覽

本文檔詳細說明了升級後的**神經網絡驅動的中樞系統**，它模擬人類大腦的多層神經元網絡，實現敏感、動態的決策能力。

### 核心特性

1. **多層神經元網絡** - 6 層神經架構
2. **動態敏感度** - 實時調整的感知能力
3. **網狀連接** - 神經元間的多維連接
4. **敏感反饋** - 多角度的輸出分析
5. **異常檢測** - 邊界條件和異常識別

## 🧠 系統架構

### 神經層結構

```
輸入層 (Input Layer)
├─ 8 個神經元
├─ 感知信號: 查詢長度、詞彙豐富度、問題傾向等
└─ 輸出: 初步信號特徵

    ↓ (信號傳遞)

語義層 (Semantic Layer)
├─ 6 個神經元
├─ 分析: 詞義、語言特性
└─ 輸出: 語義特徵向量

    ↓ (信號聚合)

上下文層 (Context Layer)
├─ 6 個神經元
├─ 分析: 歷史對話、相關性
└─ 輸出: 上下文評分

    ↓ (情感影響)

情感層 (Emotion Layer)
├─ 5 個神經元
├─ 分析: 查詢情感傾向
└─ 輸出: 情感敏感度

    ↓ (決策聚合)

輸出層 (Output Layer)
├─ 5 個神經元
├─ 綜合: 所有層的信息
└─ 輸出: 最終決策和置信度
```

### 神經網絡連接

```
Input → Semantic (全連接，權重: 0.5±0.1)
        ↓
      Context (全連接，權重: 0.6)
        ↓
      Emotion (全連接，權重: 0.7)
        ↓
      Output (全連接，權重: 0.8)
```

## 🔍 輸入信號解析

系統將查詢轉換為 8 維信號向量：

| 信號 # | 名稱       | 範圍 | 說明                              |
| ------ | ---------- | ---- | --------------------------------- |
| 0      | 查詢長度   | 0-1  | 字符數 / 100 (歸一化)             |
| 1      | 詞彙豐富度 | 0-1  | 唯一詞數 / 20 (歸一化)            |
| 2      | 問題傾向   | 0-1  | 1.0 (有?) / 0.5 (無?)             |
| 3      | 技術性     | 0-1  | 英文字符比例                      |
| 4      | 複雜度     | 0-1  | 句子數 / 5 (歸一化)               |
| 5      | 情感傾向   | 0-1  | 積極(0.8) / 消極(0.2) / 中立(0.5) |
| 6      | 專業性     | 0-1  | 技術詞彙數 / 3 (歸一化)           |
| 7      | 緊急性     | 0-1  | 1.0 (緊急) / 0.3 (非緊急)         |

**示例：**

```
查詢: "如何優化 Python 代碼性能?"
信號: [0.17, 0.15, 1.00, 0.53, 0.20, 0.50, 0.00, 0.30]
└─ 長度:17字, 詞彙:3個, 有問號, 技術詞彙比高, 複雜度低, 中立情感, 非緊急
```

### 解讀激活值

- **高激活** (> 0.7): 系統高度確定，信息清晰

- **低激活** (< 0.4): 系統不確定，需要澄清

## 🎯 敏感度指標（多維度分析）

系統不再只返回單一分數，而是返回**多維敏感度向量**：

```python
sensitivity_indicators = {
    'keyword_sensitivity': 0.68,      # 關鍵詞匹配敏感度
    'context_sensitivity': 0.613,     # 上下文理解敏感度
    'emotion_sensitivity': 0.605,     # 情感感知敏感度
    'relevance_confidence': 0.45,     # 相關性信心度
    'overall_sensitivity': 0.627      # 整體敏感度
}
```

### 敏感度的含義

**Keyword Sensitivity (關鍵詞敏感度)**

- 衡量系統對查詢中關鍵詞的識別能力
- 高值 = 找到明確的相關對話
- 低值 = 關鍵詞模糊不清

**Context Sensitivity (上下文敏感度)**

- 衡量系統對對話上下文的理解能力
- 高值 = 能提供有意義的上下文
- 低值 = 缺乏相關的歷史對話

**Emotion Sensitivity (情感敏感度)**

- 衡量系統對查詢情感傾向的理解
- 高值 = 查詢情感明確
- 低值 = 情感傾向不清

**Relevance Confidence (相關性信心)**

- 衡量系統對查詢-對話匹配的信心
- 高值 = 有信心提供相關答案
- 低值 = 相關對話較少

## 🚨 邊界條件檢測 (Boundary Conditions)

系統偵測查詢是否在其能力範圍內：

```python
boundary_conditions = {
    'high_confidence': True,           # 有足夠的相似對話
    'clear_intent': True,              # 查詢意圖清晰
    'sufficient_context': True,        # 查詢信息充分
    'within_domain': True,             # 在系統領域內
    'requires_clarification': True    # 不需要澄清
}
```

### 邊界條件的含義

| 條件                     | 含義             | 含義反向     |
| ------------------------ | ---------------- | ------------ |
| `high_confidence`        | 有 2+ 相似對話   | 查詢過於特殊 |
| `clear_intent`           | 輸入層激活 > 0.6 | 查詢目的不明 |
| `sufficient_context`     | 查詢 > 10 字     | 信息不足     |
| `within_domain`          | 最高相關度 > 30  | 超出領域     |
| `requires_clarification` | 需要澄清 = False | 需要更多信息 |

## 🔍 異常檢測 (Anomaly Detection)

系統會識別異常或邊界情況：

```python
anomaly_score = 0.96  # 0-1 範圍，越高越異常

計算邏輯:
├─ 無相關對話: +0.80 (異常)
├─ 低平均相關度: +0.20 (部分異常)
├─ 超長查詢: ×1.1 (加權)
└─ 最終: min(異常值, 1.0)
```

### 異常分數解讀

- **0.0-0.3**: 正常查詢，系統熟悉
- **0.3-0.6**: 邊界查詢，部分異常
- **0.6-1.0**: 異常查詢，新領域或特殊情況

## 🎓 理論背景

### 為什麼是神經網絡？

1. **多層抽象**
   - 輸入層: 原始信號
   - 隱藏層: 語義、上下文、情感提取
   - 輸出層: 綜合決策

2. **非線性決策**
   - 使用 sigmoid 激活函數
   - 捕捉複雜的輸入-輸出關係
   - 比簡單規則更靈活

3. **動態敏感度**
   - 每個神經元有獨立的敏感度
   - 可根據使用場景調整
   - 實現自適應學習

4. **容錯性**
   - 多條信息傳導路徑
   - 單個異常不會造成系統失敗
   - 類似人類大腦的魯棒性

## 📞 故障排除

### 激活值總是低

- 檢查輸入信號是否正常
- 增加神經元敏感度
- 驗證連接權重

### 異常分數過高

- 可能查詢超出領域
- 嘗試提供更多上下文
- 檢查邊界條件提示

### 敏感度指標不平衡

- 這是正常的（反映不同維度）
- 查看整體敏感度 (`overall_sensitivity`)
- 根據具體維度調整策略
