## 各模塊使用

### 📚 對話學習提取模塊

**用途**: 從對話中自動提取知識

**基本使用**:

```python
from learning.conversation_learning_extractor import ConversationLearningExtractor

# 初始化
extractor = ConversationLearningExtractor(
    conversations_file="data/conversations.json"
)

# 提取所有知識
all_knowledge = extractor.extract_all_knowledge()

# 查看結果
print(f"📊 提取知識: {len(all_knowledge)} 項")
for kb in all_knowledge[:3]:
    print(f"  - {kb['type']}: {kb['concept']} (優先級: {kb['priority']})")

# 生成訓練數據
training_data = extractor.generate_training_data_for_local_model()
print(f"📈 訓練集已生成: {len(training_data)} 條")
```

**輸出字段解釋**:

- `type`: 知識類型 (code_example, concept, best_practice 等)
- `priority`: 優先級 (critical > high > medium > low)
- `relevance_score`: 相關性 (0-1)
- `training_data`: 對應訓練示例

**進階用法**:

```python
# 按優先級過濾
critical = [k for k in all_knowledge if k['priority'] == 'critical']

# 按類型分類
by_type = {}
for k in all_knowledge:
    by_type.setdefault(k['type'], []).append(k)

# 自定義評分
high_quality = [k for k in all_knowledge if k['relevance_score'] > 0.7]

print(f"🔴 Critical 級別: {len(critical)}")
print(f"📊 按類型分布: {list(by_type.keys())}")
print(f"⭐ 高質量知識: {len(high_quality)}")
```

### 🧠 神經索引增強模塊

**用途**: 建立 768 維向量索引，加速知識檢索

**基本使用**:

```python
from learning.enhanced_neural_index import EnhancedNeuralIndex

# 初始化索引
index = EnhancedNeuralIndex(dimensions=768)

# 添加知識
knowledge_items = [
    {
        "id": "kb_001",
        "content": "Python 列表推導式用法",
        "embedding": [0.1, 0.2, ...],  # 768 維向量
        "importance": 0.85
    },
    # ... 更多項目
]

for item in knowledge_items:
    index.add_neuron(item)

print(f"✅ 已添加 {len(knowledge_items)} 個神經元")

# 檢索相似知識
query = [0.1, 0.2, ...]  # 查詢向量
results = index.retrieve_relevant_neurons(query, top_k=5)

print(f"🔍 檢索結果 (Top 5):")
for i, result in enumerate(results, 1):
    print(f"  {i}. {result['content']} (相似度: {result['similarity']:.2%})")

# 優化索引
index.optimize_neural_structure()
print(f"⚡ 索引已優化 (延遲 < 100ms)")
```

**關鍵方法**:
| 方法 | 用途 | 參數 |
|------|------|------|
| `add_neuron()` | 添加知識 | item dict |
| `retrieve_relevant_neurons()` | 查詢檢索 | query, top_k |
| `update_neuron_connection()` | 更新連接 | from_id, to_id |
| `optimize_neural_structure()` | 優化索引 | - |

**用途**: 自動掃描、評估、接受/拒絕項目機會，管理收益

**基本使用**:

```python

manager.acceptable_task_min_revenue = 500      # 最小 ¥500
```

### 工作流 #2: 自動接案

**場景**: 定期掃描機會→自動評估→接受合適任務→生成記錄

```python
# step_2_auto_task_acceptance.py

from business.task_and_revenue_manager import TaskAndRevenueManager
from learning.conversation_logger import ConversationLogger
import json
import time

manager = TaskAndRevenueManager()
logger = ConversationLogger()

# 配置接案標準
manager.acceptable_task_min_revenue = 500
manager.work_capacity = 100
manager.current_load = 20  # 當前 20% 負荷

print("🤖 自動接案流程")
print("=" * 50)

# 模擬掃描機會
mock_opportunities = [
    {
        "id": "opp_001",
        "title": "Django 應用性能優化",
        "budget": 12000,
        "estimated_hours": 50,
        "type": "optimization"
    },
    {
        "id": "opp_002",
        "title": "寫技術博客",
        "budget": 2000,
        "estimated_hours": 20,
        "type": "content"
    },
    {
        "id": "opp_003",
        "title": "小型咨詢",
        "budget": 400,  # 低於最低值
        "estimated_hours": 4,
        "type": "consultation"
    }
]

accepted_count = 0
total_revenue = 0

for opp in mock_opportunities:
    print(f"\n📋 評估: {opp['title']}")
    print(f"   預算: ¥{opp['budget']} | 工時: {opp['estimated_hours']}h")

    # 評估
    assessment = manager.assess_task_opportunity(opp)

    if assessment['decision'] == 'accept':
        # 分配任務
        task = manager.assign_task(opp)
        print(f"   ✅ 已接受 (淨收益: ¥{assessment['net_revenue']:.0f})")

        # 記錄
        logger.record_optimization(
            component="business_system",
            change=f"Accepted task: {opp['id']}",
            impact={"revenue": assessment['net_revenue']}
        )

        accepted_count += 1
        total_revenue += assessment['net_revenue']
    else:
        print(f"   ❌ 已拒絕: {assessment['rejection_reason']}")

# 總結
print("\n" + "=" * 50)
print(f"✅ 處理完成")
print(f"   已接受: {accepted_count} 個任務")
print(f"   預期收益: ¥{total_revenue:.0f}")

# 保存到日誌
summary = {
    "timestamp": time.strftime("%Y-%m-%d %H:%M:%S"),
    "opportunities_evaluated": len(mock_opportunities),
    "opportunities_accepted": accepted_count,
    "total_expected_revenue": total_revenue
}
print(json.dumps(summary, indent=2, ensure_ascii=False))
```

**運行**:

```bash
python3 step_2_auto_task_acceptance.py
```
