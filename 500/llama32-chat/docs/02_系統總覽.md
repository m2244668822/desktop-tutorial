## 🔗 中樞神經（Central Nervous System）連結

### autonomous_agent.py 的核心職責

```
┌─────────────────────────────────────────┐
│   中樞神經 (AutonomousAgent)            │
├─────────────────────────────────────────┤
│                                         │
│  1️⃣ 模型選擇與故障轉移                  │
│  ├─ 智能選擇最適合的模型                │
│  ├─ 自動故障轉移（A→B→C）              │
│  └─ 健康狀態監控                       │
│                                         │
│  2️⃣ 性能監控                          │
│  ├─ 追踨每個模型的成功率                │
│  ├─ 計算響應時間                       │
│  └─ 記錄使用成本                       │
│                                         │
│  3️⃣ 決策制定                          │
│  ├─ 根據任務類型選模型                  │
│  ├─ 根據模型狀態調整策略                │
│  └─ 優化資源分配                       │
│                                         │
│  4️⃣ 智能體協調                        │
│  ├─ 管理所有智能體                      │
│  ├─ 分配任務給最適合的智能體            │
│  └─ 聚合結果                           │
│                                         │
│  5️⃣ 事件驅動設計                     │
│  ├─ 訂閱智能體事件                      │
│  ├─ 即時響應故障                       │
│  └─ 協調跨智能體的工作流                │
│                                         │
└─────────────────────────────────────────┘
```

### 與智能體的連接方式

```python
# 1. 註冊智能體
agent_registry.register(
    "central_nervous",
    "自主決策引擎",
    ["決策制定", "協調", "監控"]
)

# 2. 訂閱智能體事件
message_broker.subscribe(
    EventType.CODE_UPDATE_COMPLETED,
    self._on_code_update_completed
)

# 3. 發布命令給智能體
message_broker.publish(Message(
    sender="central_nervous",
    event_type=EventType.TASK_ASSIGNED,
    data=task_info
))

# 4. 聚集智能體狀態
status = agent_registry.get_all_agents()
```

## 🔄 數據流和通信模式

### 場景 1：簡單聊天

```
用戶輸入
   ↓
chat.py 解析命令
   ↓
調用 autonomous_agent
   ↓
中樞神經判斷：
  ├─ 任務類型？
  ├─ 最佳模型？
  └─ 模型狀態？
   ↓
選擇模型 (Ollama / OpenAI / Gemini)
   ↓
調用 AI 模型
   ↓
保存對話到 conversations.json
   ↓
返回結果給用戶
```

### 場景 2：任務管理

```
用戶創建任務
   ↓
task_manager.py 添加到 tasks.json
   ↓
chat.py --tasks 執行
   ↓
中樞神經分配任務：
  ├─ 讀取 tasks.json
  ├─ 根據優先級排序
  ├─ 為每個任務選擇模型
  └─ 發送到對應的智能體
   ↓
智能體執行任務
   ↓
發布完成事件
   ↓
中樞神經聚集結果
   ↓
更新 history.json
   ↓
返回統計信息
```

### 場景 3：故障恢復

```
模型 A 調用失敗
   ↓
智能體記錄失敗
   ↓
發布 FAILED 事件
   ↓
中樞神經接收事件
   ↓
檢查模型 A 的連續失敗次數
   ↓
超過門檻？
├─ 是：標記模型冷卻
├─ 否：繼續嘗試
   ↓
自動選擇備用模型 B
   ↓
重新執行任務
   ↓
成功：保存數據
失敗：嘗試模型 C
```

## 🎓 工作流示例

### 創建和執行任務流程

```
1. 編輯 tasks/tasks.json
   添加新任務，如："用 Python 寫一個排序算法"

2. 執行命令
   $ python core/chat.py --tasks

3. 中樣神經的決策過程：
   ✓ 検測了"代碼"任務 → 選擇 Gemini
   ✓ Gemini 連接失敗 → 自動轉移到 OpenAI
   ✓ 執行成功 → 保存到 history.json
   ✓ 生成報告 → 顯示統計信息

4. 検查結果
   $ python core/chat.py --monitor-tasks
   看到任務已完成及耗時
```

### 智能故障恢復流程

```
1. 用戶要求："解釋機器學習"
   $ python core/chat.py "解釋機器學習"

2. 系統決策：
   ✓ 這是教育/解釋任務 → 優先選 Ollama（快速）

3. 執行：
   ✗ Ollama 連接失敗
   ✓ 檢查 Ollama 狀態 → 標記為故障
   ✓ 自動選擇 Gemini → 成功執行

4. 記錄：
   - 對話保存到 conversations.json
   - 故障信息記錄到 agent.log
   - 性能數據更新到 agent_performance.json
```
