# 進階認知能力系統使用指南

## 概述

進階認知能力系統為智能體提供了多種高階認知模式，提升其推理、學習和決策能力。

## 核心能力

### 1. 反思型能力 (Reflective)

**用途**: 對過往決策和行為進行反思與評估

**使用方法**:

```python
from core.autonomous_agent import autonomous_agent

result = autonomous_agent.reflect_on_decision(
    decision="選擇使用快取來提升性能",
    outcome="成功減少了50%的響應時間",
    context={"system": "chat_system"}
)

print(f"質量評分: {result['quality_score']}/10")
print(f"關鍵教訓: {result['lessons_learned']}")
print(f"改進建議: {result['improvements']}")
```

**應用場景**:

- 模型選擇決策後的評估
- 系統優化方案的回顧
- 錯誤處理策略的反思

---

### 2. 挑戰型能力 (Challenge)

**用途**: 質疑假設、尋找反例、測試邊界

**使用方法**:

```python
result = autonomous_agent.challenge_assumption(
    assumption="所有用戶總是偏好更快的響應速度",
    evidence=["用戶調查顯示80%用戶選擇速度", "性能測試證實更快"],
    context={"domain": "user_experience"}
)

print(f"假設強度: {result['strength']}/10")
print(f"反例: {result['counter_examples']}")
print(f"需要修正: {result['should_revise']}")
```

**應用場景**:

- 驗證系統設計假設
- 測試優化策略的普適性
- 發現潛在的邊界條件

---

### 3. 信心校準能力 (Confidence Calibration)

**用途**: 評估和校正信心水平，避免過度自信或不足

**使用方法**:

```python
result = autonomous_agent.calibrate_confidence(
    prediction="系統在高負載下仍能保持穩定",
    initial_confidence=0.9,
    supporting_factors=["已通過壓力測試", "有冗餘設計"],
    uncertainty_factors=["未測試極端情況", "依賴第三方服務"]
)

print(f"初始信心: {result['initial_confidence']:.2%}")
print(f"校準後信心: {result['calibrated_confidence']:.2%}")
print(f"信心等級: {result['confidence_level']}")
```

**應用場景**:

- 預測準確度評估
- 決策風險評估
- 模型性能預期校準

---

### 4. 主動假說能力 (Active Hypothesis)

**用途**: 主動提出假說並設計驗證方法

**使用方法**:

```python
result = autonomous_agent.generate_hypotheses(
    observation="系統在高峰時段出現間歇性響應緩慢",
    context={
        "system": "chat_api",
        "peak_hours": "18:00-21:00"
    }
)

print(f"生成假說: {result['hypotheses']}")
print(f"優先假說: {result['ranked_hypotheses'][0]}")
print(f"驗證計劃: {result['verification_plans']}")
```

**應用場景**:

- 問題診斷
- 性能異常分析
- 系統行為預測

---

### 5. 失敗分析能力 (Failure Analysis)

**用途**: 深度分析失敗原因並提取規律

**使用方法**:

```python
failure_event = {
    "model": "openai",
    "error_message": "Connection timeout",
    "error_type": "timeout_error",
    "consecutive_failures": 3
}

result = autonomous_agent.analyze_failure_with_cognition(
    failure_event=failure_event,
    historical_failures=[]
)

print(f"失敗類型: {result['failure_type']}")
print(f"根本原因: {result['root_causes']}")
print(f"防範措施: {result['preventive_measures']}")
```

**應用場景**:

- 模型調用失敗分析
- 系統錯誤模式識別
- 預防性維護策略制定

---

### 6. 類比遷移能力 (Analogy Transfer)

**用途**: 從已知領域遷移知識到新領域

**使用方法**:

```python
result = autonomous_agent.transfer_knowledge(
    source_domain="Web 應用快取策略",
    target_domain="AI 模型響應快取",
    source_solution="使用 Redis 作為分散式快取",
    context={"source_scale": "high_traffic_web"}
)

print(f"遷移可信度: {result['transferability']:.2%}")
print(f"適配方案: {result['adapted_solution']}")
print(f"潛在陷阱: {result['pitfalls']}")
```

**應用場景**:

- 跨領域解決方案遷移
- 經驗知識復用
- 創新方案設計

---

### 7. 概念提取能力 (Concept Extraction)

**用途**: 從具體實例中抽象出通用概念

**使用方法**:

```python
examples = [
    {"type": "timeout_error", "retry_count": 3, "success": False},
    {"type": "connection_error", "retry_count": 2, "success": False},
    {"type": "timeout_error", "retry_count": 1, "success": True}
]

result = autonomous_agent.extract_concepts(
    examples=examples,
    context={"domain": "error_handling"}
)

print(f"共同模式: {result['common_patterns']}")
print(f"核心概念: {result['core_concepts']}")
print(f"概念層次: {result['concept_hierarchy']}")
```

**應用場景**:

- 錯誤模式歸納
- 知識庫構建
- 規則提取

---

### 8. 查詢處理能力 (Query Processing)

包含四種子能力：

#### 8.1 時效性查詢

**用途**: 處理有時間約束的查詢

```python
result = autonomous_agent.process_temporal_query(
    query="獲取最近24小時內的系統錯誤",
    time_context={
        "current_time": "2026-04-16T12:00:00",
        "last_update": "2026-04-16T11:50:00"
    }
)

print(f"時間敏感: {result['is_time_sensitive']}")
print(f"數據新鮮度: {result['data_freshness']:.2%}")
```

#### 8.2 缺口填補查詢

**用途**: 推斷缺失數據

```python
result = autonomous_agent.process_gap_filling_query(
    known_data={"model": "ollama", "error_type": "timeout"},
    missing_fields=["timestamp", "retry_count", "status"]
)

print(f"推斷值: {result['inferred_values']}")
print(f"推斷信心: {result['inference_confidence']}")
```

#### 8.3 驗證式查詢

**用途**: 驗證聲明的真實性

```python
result = autonomous_agent.process_verification_query(
    claim="Ollama 模型適合處理簡單對話任務",
    evidence=["本地運行速度快", "無需網絡連接"],
    context={"domain": "model_selection"}
)

print(f"驗證結果: {result['is_verified']}")
print(f"支持度: {result['support_score']:.2%}")
```

#### 8.4 分解式查詢

**用途**: 將複雜查詢分解為子問題

```python
result = autonomous_agent.process_decomposition_query(
    complex_query="分析過去7天的性能，生成報告，並發送給管理員",
    context={"system": "monitoring"}
)

print(f"子問題: {result['sub_queries']}")
print(f"執行計劃: {result['execution_plan']}")
```

## 完整示例：智能失敗處理

```python
from core.autonomous_agent import autonomous_agent

# 模擬一次模型調用失敗
model = "openai"
error_message = "Connection timeout after 30 seconds"

# 使用增強失敗處理（自動整合多種認知能力）
autonomous_agent.enhanced_failure_handling(
    model=model,
    error_message=error_message,
    error_type="timeout_error"
)

# 系統會自動：
# 1. 記錄失敗（標準流程）
# 2. 執行失敗分析（識別根本原因）
# 3. 生成假說（推測可能原因）
# 4. 反思決策（評估模型選擇）
# 5. 發佈學習事件（通知其他智能體）
```

## 最佳實踐

### 1. 合理使用反思能力

- ✅ 在重要決策後進行反思
- ✅ 定期回顧系統行為
- ❌ 避免對每個微小操作都反思

### 2. 挑戰關鍵假設

- ✅ 挑戰系統設計的核心假設
- ✅ 在做重大變更前質疑前提
- ❌ 不要挑戰已充分驗證的基本事實

### 3. 校準信心水平

- ✅ 在做預測時使用信心校準
- ✅ 考慮支持和不確定因素
- ❌ 不要忽視不確定性

### 4. 主動生成假說

- ✅ 遇到異常時立即生成假說
- ✅ 設計可驗證的假說
- ❌ 不要只依賴直覺判斷

### 5. 深入分析失敗

- ✅ 記錄每次失敗的詳細信息
- ✅ 尋找失敗模式
- ✅ 制定預防措施
- ❌ 不要簡單歸因於單一原因

### 6. 謹慎遷移知識

- ✅ 評估領域相似度
- ✅ 識別潛在陷阱
- ❌ 不要盲目套用解決方案

### 7. 提取可復用概念

- ✅ 從多個實例中歸納
- ✅ 建立概念層次
- ❌ 不要過早泛化

### 8. 智能處理查詢

- ✅ 根據查詢類型選擇合適的處理方式
- ✅ 分解複雜查詢
- ❌ 不要對簡單查詢過度處理

## 性能考慮

1. **適時使用**: 認知能力處理需要額外計算，在關鍵決策點使用
2. **並行處理**: 多個獨立的認知處理可以並行執行
3. **結果快取**: 相似的認知處理可以快取結果
4. **漸進式分析**: 從簡單分析開始，必要時深入

## 故障排查

### 問題：認知能力系統未初始化

**解決方案**:

```python
# 檢查是否正確導入
from core.autonomous_agent import autonomous_agent

# 檢查認知管理器狀態
if autonomous_agent.cognitive_manager:
    print("✅ 認知能力系統可用")
else:
    print("❌ 認知能力系統未初始化")
```

### 問題：信心度異常低

**原因**: 可能是證據不足或存在過多不確定因素

**解決方案**:

- 提供更多支持性證據
- 減少不確定性因素
- 檢查輸入數據的質量

## 進階用法

### 組合使用多種能力

```python
# 步驟1：生成假說
hypotheses = autonomous_agent.generate_hypotheses(
    observation="性能下降",
    context={}
)

# 步驟2：挑戰最可能的假說
top_hypothesis = hypotheses['ranked_hypotheses'][0]
challenge = autonomous_agent.challenge_assumption(
    assumption=top_hypothesis,
    evidence=["觀察到的現象1", "觀察到的現象2"],
    context={}
)

# 步驟3：校準信心
if not challenge['should_revise']:
    confidence = autonomous_agent.calibrate_confidence(
        prediction=top_hypothesis,
        initial_confidence=0.8,
        supporting_factors=challenge['counter_examples'],
        uncertainty_factors=["需要更多數據"]
    )
```
