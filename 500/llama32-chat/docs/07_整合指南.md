### 2. 智能體通信整合

#### 創建自定義智能體

```python
from agents.agent import BaseAgent
from agents.agent_communication import message_broker, agent_registry, EventType, Message

class MyCustomAgent(BaseAgent):
    def __init__(self):
        super().__init__("my_agent", "我的自定義智能體")

        # 註冊智能體
        agent_registry.register(
            self.agent_id,
            self.description,
            ["自定義功能1", "自定義功能2"]
        )

        # 訂閱事件
        message_broker.subscribe(
            EventType.TASK_COMPLETED,
            self.on_task_completed
        )

    def handle_message(self, message: Message):
        """處理接收到的消息"""
        print(f"收到消息: {message.event_type}")
        # 自定義處理邏輯

    def on_task_completed(self, message: Message):
        """任務完成事件處理"""
        task_id = message.data.get('task_id')
        print(f"任務 {task_id} 已完成")

# 使用
agent = MyCustomAgent()
```

#### 發布和訂閱消息

```python
from agents.agent_communication import message_broker, EventType, Message

# 發布消息
message_broker.publish(Message(
    sender="my_agent",
    event_type=EventType.TASK_CREATED,
    data={
        "task_id": "task_001",
        "description": "處理數據"
    }
))

# 訂閱消息
def my_callback(message):
    print(f"收到任務: {message.data}")

message_broker.subscribe(EventType.TASK_CREATED, my_callback)
```

### 模式 3: 完整整合

包含所有功能（神經系統、RAG、監控等）。

```python
# full_integration.py
from learning.neural_chat import NeuralChat
from learning.rag_pipeline import RAGPipeline
from agents.task_manager import TaskManager
from agents.agent_communication import message_broker

# 初始化所有組件
chat = NeuralChat()
rag = RAGPipeline(use_chroma=True)
task_mgr = TaskManager()

# 使用神經聊天 + RAG 增強
def enhanced_chat(query):
    # 檢索相關上下文
    context = rag.retrieve_similar_conversations(query, top_k=3)

    # 構建增強查詢
    enhanced = f"參考: {context}\n\n問題: {query}"

    # 發送到神經聊天
    result = chat.chat(enhanced)

    return result

# 使用
response = enhanced_chat("Python 異步編程最佳實踐")
print(response['response'])
```

## 🐛 常見整合問題

### 問題 1: 模型調用失敗

**症狀**: `Error: Model XXX not available`

**解決**:

1. 檢查 API Key 是否正確
2. 驗證網路連接
3. 查看模型服務狀態
4. 檢查配額限制

```bash
# 檢查配置
python -c "from dotenv import load_dotenv; import os; load_dotenv(); print(os.getenv('GEMINI_API_KEY'))"

# 測試連接
python core/chat.py --health-check
```

### 問題 2: 導入數據失敗

**症狀**: `Error: Invalid conversation format`

**解決**:

1. 驗證 JSON 格式
2. 檢查數據結構
3. 使用格式檢測工具

```bash
# 檢測格式
python detect_openai_format.py conversations.json

# 轉換格式
python convert_openai_data.py conversations.json output.json
```

### 問題 3: 智能體通信問題

**症狀**: 消息未被接收

**解決**:

1. 確認已訂閱事件
2. 檢查事件類型匹配
3. 驗證消息格式

```python
# 調試消息
import logging
logging.basicConfig(level=logging.DEBUG)

# 檢查訂閱者
from agents.agent_communication import message_broker
print(message_broker.subscribers)
```

### 問題 4: 性能問題

**症狀**: 響應緩慢

**解決**:

1. 啟用緩存
2. 優化 RAG 檢索
3. 調整並發數
4. 使用本地模型

```python
# 啟用緩存
from core.autonomous_agent import AutonomousAgent
agent = AutonomousAgent(enable_cache=True)

# 使用快速模型
result = agent.chat("問題", model="ollama")
```
