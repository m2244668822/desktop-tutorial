# 對話記錄學習系統 - 使用指南

## 📚 概述

對話記錄學習系統可以自動記錄你與 AI 助手的每次對話和編程會話，讓智能體從這些經驗中學習和成長。

## 🎯 核心功能

### 1. 對話記錄 (log_conversation)

記錄用戶與 AI 的單次對話交互

### 2. 編程會話記錄 (log_programming_session)

記錄完整的編程任務，包括：

- 任務描述
- 代碼變更
- 解決方案
- 學習要點

### 3. 學習筆記 (add_learning_note)

記錄重要的知識點和經驗

### 4. 數據導出 (export_learning_data)

導出所有學習數據供分析

## 🚀 快速開始

### 自動記錄當前會話

```bash
python log_current_session.py
```

### 手動記錄對話

```python
from core.conversation_logger import ConversationLogger

logger = ConversationLogger()

# 記錄一次對話
logger.log_conversation(
    user_message="如何優化 Python 性能？",
    assistant_response="可以使用以下方法...",
    tags=["python", "optimization"]
)
```

### 記錄編程會話

```python
logger.log_programming_session(
    task_description="實現用戶登錄功能",
    code_changes=[
        {"file": "auth.py", "description": "添加 login 函數"},
        {"file": "models.py", "description": "創建 User 模型"}
    ],
    solutions=[
        "使用 JWT 進行身份驗證",
        "密碼使用 bcrypt 加密"
    ],
    learnings=[
        "JWT token 應該設置合理的過期時間",
        "密碼加密要使用安全的算法"
    ]
)
```

### 添加學習筆記

```python
logger.add_learning_note(
    topic="調試技巧",
    content="使用 print 語句時記得在完成後刪除",
    category="debugging"
)
```

## 📊 查看學習數據

### 獲取學習摘要

```python
summary = logger.get_learning_summary()
print(f"總對話數: {summary['total_conversations']}")
print(f"總會話數: {summary['total_sessions']}")
print(f"熱門標籤: {summary['popular_tags']}")
```

### 導出數據

```python
logger.export_learning_data("my_learning_data.json")
```

## 📁 數據文件位置

- **data/conversations.json** - 所有對話記錄
- **data/learning_log.json** - 學習日誌（會話和筆記）
- **data/learning_data_YYYYMMDD.json** - 導出的學習數據

## 🔍 數據格式

### 對話記錄格式

```json
{
  "id": "conv_20260227_160227",
  "timestamp": "2026-02-27T16:02:27.123456",
  "messages": [
    { "role": "user", "content": "用戶消息" },
    { "role": "assistant", "content": "AI 回應" }
  ],
  "context": {},
  "tags": ["tag1", "tag2"],
  "learning_enabled": true
}
```

### 編程會話格式

```json
{
  "id": "session_20260227_160226",
  "type": "programming_session",
  "task": "任務描述",
  "code_changes": [...],
  "solutions": [...],
  "learnings": [...]
}
```

## 💡 使用建議

### 何時記錄

1. **每次完成一個功能** - 記錄編程會話
2. **解決一個問題後** - 添加學習筆記
3. **與 AI 深入討論後** - 記錄對話
4. **發現新技巧時** - 立即記錄

### 標籤分類建議

- **技術類**: python, javascript, database, api
- **任務類**: debugging, optimization, refactoring, testing
- **階段類**: design, implementation, deployment, maintenance

### 學習筆記分類

- **debugging** - 調試技巧和問題解決
- **optimization** - 性能優化經驗
- **architecture** - 架構設計決策
- **documentation** - 文檔編寫經驗
- **general** - 其他通用知識

## 🔄 與 AI 系統集成

### 讓 AI 分析學習數據

```bash

python core/chat.py "我在調試方面學到了什麼？"
```

### 自動化記錄

可以在 `chat.py` 或其他腳本中集成自動記錄：

```python

# 在對話結束後自動記錄
quick_log(
    user_msg=user_input,
    assistant_msg=ai_response,
    tags=["auto", "chat"]
)
```

## 🔧 進階使用

### 批量記錄歷史對話

如果有歷史對話數據（如從 ChatGPT 導出的文件），可以批量導入：

```python
from core.conversation_logger import ConversationLogger
import json

logger = ConversationLogger()

# 讀取歷史數據
with open('本地/opai本地/conversations-000.json', 'r') as f:
    old_convs = json.load(f)

# 批量記錄
for conv in old_convs:
    logger.log_conversation(
        user_message=conv['user'],
        assistant_response=conv['assistant'],
        tags=['imported', 'openai']
    )
```

## 🆘 常見問題

### Q: 數據會占用很多空間嗎？

A: 文本數據很小，即使記錄數千次對話也只需幾 MB。

### Q: 如何刪除舊數據？

A: 編輯 `data/conversations.json` 和 `data/learning_log.json`，刪除不需要的條目。

### Q: 可以同步到雲端嗎？

A: 可以！只需將 `data/` 資料夾加入 Git 或同步到雲端硬碟。

### Q: AI 如何使用這些數據？

A: 通過 RAG 管線（`rag_pipeline.py`），AI 可以檢索和參考這些對話記錄。
