# 中期改進快速使用指南

## 🚀 新功能速覽

### 1️⃣ 分頁加載 API

**優勢**: 大數據集高效訪問，節省內存

```bash
# 查看第1頁（默認50條/頁）
python3 tools/local_memory_api.py --page 1

# 自定義每頁數量
python3 tools/local_memory_api.py --page 2 --page-size 100
```

**Python API**:

```python
from local_memory_api import LocalMemoryAPI

api = LocalMemoryAPI()
result = api.get_conversations_paginated(page=1, page_size=50)

print(f"總共 {result['pagination']['total_pages']} 頁")
print(f"當前第 {result['pagination']['page']} 頁")
```

---

### 2️⃣ 搜索自動擴展

**優勢**: 智能擴展搜索範圍，找到更多結果

```python
# 自動擴展（默認開啟）
results = api.search_conversations(query="履歷", limit=10)
# 結果少時自動加載完整數據庫

# 禁用自動擴展
results = api.search_conversations(query="履歷", limit=10, auto_expand=False)
```

**實際效果**:

- 初始搜索：2 條結果
- 自動擴展後：10 條結果（+400%）

---

### 3️⃣ 智能緩存管理

**優勢**: 多層緩存提升性能

```bash
# 查看緩存統計
python3 tools/local_memory_api.py --cache-stats

# 清除搜索緩存
python3 tools/local_memory_api.py --clear-cache search

# 清除所有緩存
python3 tools/local_memory_api.py --clear-cache all
```

**Python API**:

```python
# 獲取緩存統計
stats = api.get_cache_stats()
print(f"命中率: {stats['hit_rate']}")

# 清除緩存
api.clear_cache('all')
```

**緩存層級**:

- Full（完整數據）: 5 分鐘
- Paginated（分頁數據）: 10 分鐘
- Search（搜索結果）: 3 分鐘

**優勢**: 全面的數據洞察和可視化

```bash

python3 tools/local_memory_api.py --dashboard
```

**Python API**:

```python
dashboard = api.get_statistics_dashboard()

# 訪問不同部分
print(dashboard['overview'])           # 概覽
```

- 💬 消息分析：平均長度 162 字符

- 💾 緩存性能：實時命中率
