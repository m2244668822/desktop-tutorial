## 故障速查

| 問題       | 解決                                |
| ---------- | ----------------------------------- |
| 系統不啟動 | 檢查 Python 版本、Ollama 狀態       |
| 檢索缓慢   | 運行 `index.optimize_index()`       |
| 無法接案   | 降低 `acceptable_task_min_revenue`  |
| 記錄問題   | 檢查 `data/conversation_logs/` 權限 |
