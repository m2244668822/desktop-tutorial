# 智能體學習系統整合說明

## 🎉 更新內容

已成功將智能體學習系統整合到聊天客戶端和開發流程中！現在系統會自動記錄所有對話和程式更新，讓智能體能夠持續學習和改進。

---

## ✨ 新增功能

### 1. **自動記錄對話** 📝

每次使用 `chat_client.py` 進行對話時，系統會自動：

- ✅ 記錄用戶消息和 AI 回應
- ✅ 標記對話類型（coding、learning、documentation 等）
- ✅ 保存上下文資訊（使用的 API、對話次數等）
- ✅ 通知智能體更新學習數據

### 2. **程式更新記錄** 🔧

使用 `code_change_tracker.py` 記錄代碼變更：

- ✅ 記錄任務描述和修改的文件
- ✅ 保存解決方案和學習要點
- ✅ 自動通知智能體系統
- ✅ 提供互動式記錄模式

### 3. **智能體學習共享** 🧠

- ✅ 自動同步學習數據到中樞神經系統
- ✅ 跨智能體共享學習洞察
- ✅ 持久化存儲所有學習記錄

### 4. **Ollama 自動啟動** 🚀

- ✅ 每次啟動時自動檢查 Ollama 服務
- ✅ 如果未運行，自動啟動服務
- ✅ 智能等待服務準備就緒

## 📚 使用方法

### 基礎對話（自動記錄）

```bash
# 在 message.txt 中輸入你的問題，然後運行：
python chat_client.py
```

系統會自動：

1. 檢查並啟動 Ollama 服務
2. 執行對話
3. 記錄到學習系統
4. 通知智能體更新

### 記錄程式更新

#### 方式 1：互動式記錄

```bash
python code_change_tracker.py --interactive
```

然後按照提示輸入：

- 任務描述
- 修改的文件
- 解決方案（可選）
- 學習要點（可選）

#### 方式 2：快速記錄範例

```bash
python code_change_tracker.py --example
```

#### 方式 3：在程式碼中使用

```python
from code_change_tracker import CodeChangeTracker

tracker = CodeChangeTracker()
tracker.log_change(
    task_description="添加新功能",
    files_changed=["file1.py", "file2.py"],
    solutions=["解決方案1", "解決方案2"],
    learnings=["學習要點1", "學習要點2"]
)
```

### 測試學習系統

```bash
python test_learning_integration.py
```

## 🐛 故障排除

### Q: 學習系統未啟動

A: 確保 `500/llama32-chat/` 目錄存在且包含所需模組

### Q: Ollama 自動啟動失敗

A:

1. 確認已安裝 Ollama (https://ollama.ai)
2. 檢查 Ollama 是否在 PATH 中: `which ollama`
3. 手動啟動測試: `ollama serve`

### Q: 對話未被記錄

A: 檢查 `data/` 目錄是否有寫入權限
