# 終端機快速操作：智能體控制台失靈救援

更新日期：2026-04-12

用途：

- 智能體控制面板沒有回覆時，改用終端機直接送訊息。
- 側欄重新 resolve、切換頁面、或 Cursor webview 失靈時，仍可看狀態與拿回結果。
- 快速確認後端、同步、任務、trace、log 是否正常。


```bash

```

## 3. 終端機直接問智能體

可用智能體：

- `dispatcher`：管理中樞 / 中控分流
- `engineer`：工程修復
- `researcher`：研究員
- `xiaobian`：小編 / 文案 / 面板提案
- `whitehat`：安全檢查
- `proclaimer`：申言者 / 反思型問題
- `learner`：學習器
- `general`：通用

範例：問申言者

```bash
AGENT=proclaimer MODEL=auto MSG='所以我是哪種聰明？' python3 - <<'PY'
import json
import os
import subprocess
import time
from pathlib import Path

base = "http://127.0.0.1:5001"
agent = os.environ.get("AGENT", "general")
model = os.environ.get("MODEL", "auto")
msg = os.environ.get("MSG", "").strip()
if not msg:
    raise SystemExit("MSG is empty")

token = ""
env_path = Path(".env")
if env_path.exists():
    for line in env_path.read_text("utf-8", errors="ignore").splitlines():
        if line.startswith("SERVER_API_TOKEN="):
            token = line.split("=", 1)[1].strip().strip('"').strip("'")
            break

headers = ["-H", "Content-Type: application/json"]
if token:
    headers += ["-H", f"Authorization: Bearer {token}", "-H", f"X-API-Token: {token}"]

payload = {"message": msg, "agent": agent, "model": model}
cmd = ["curl", "-sS", "-X", "POST", *headers, "-d", json.dumps(payload, ensure_ascii=False), f"{base}/chat/agent"]
raw = subprocess.check_output(cmd, text=True)

try:
    data = json.loads(raw)
except json.JSONDecodeError:
    print(raw)
    raise SystemExit(1)

reply = str(data.get("response") or data.get("reply") or data.get("message") or "").strip()
print("agent:", data.get("agent", agent))
print("model:", data.get("model", model))
print("status:", "ok" if reply else "empty_reply")
print()
print(reply or json.dumps(data, ensure_ascii=False, indent=2))

log_dir = Path("logs")
log_dir.mkdir(exist_ok=True)
stamp = time.strftime("%Y%m%d_%H%M%S")
(log_dir / f"terminal_agent_reply_{stamp}.txt").write_text(
    f"agent={agent}\nmodel={model}\nmessage={msg}\n\n{reply or raw}\n",
    encoding="utf-8",
)
PY
```

## 4. 如果送出後沒有回覆

先看最近 trace：

```bash
curl -sS http://127.0.0.1:5001/trace/latest?limit=5 | python3 -m json.tool
```

再看監控 log：

```bash
tail -n 120 logs/ai_monitor.log
```

再看服務狀態：

```bash
curl -sS http://127.0.0.1:5001/system/model-status | python3 -m json.tool
```

常見判斷：

- `empty_reply`：後端有回 JSON，但模型回覆欄位是空的。
- `timeout`：模型呼叫太久，改用 `model=groq`、`model=openai` 或 `model=auto` 重試。
- `403`：token 沒帶到，確認 `.env` 有 `SERVER_API_TOKEN`。
- `failed to fetch`：側欄連不到後端，先跑 `/health`。

## 9. 控制面板重新 resolve 回初始值的修復說明

已修復項目：

- 側欄 webview 加上 `retainContextWhenHidden`，切換側欄時盡量保留畫面 context。
- 前端使用 `vscode.setState()` 保存控制台狀態。
- 重新 resolve 時使用 `vscode.getState()` 回填：
  - 選中的智能體
  - 選中的模型
  - 輸入草稿
  - 全量同步 job id
  - 半同步 job id
  - 上一則智能體回覆
  - 輸出紀錄
- 恢復成功時會在輸出紀錄顯示：

```text
已恢復上次控制台狀態：智能體、模型、輸入草稿、job_id、上一則回覆與輸出紀錄。
```

如果 Cursor 已經開著，修復後需要重新載入視窗：

```text
Command Palette -> Developer: Reload Window
```
