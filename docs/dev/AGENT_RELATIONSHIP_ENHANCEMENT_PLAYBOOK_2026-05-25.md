# 智能體關係強化與訓練分流落地說明（2026-05-25）

## 你要的目標（生活化）
把系統從「每次聊天像一次性訊息」變成「每次聊天都在累積團隊記憶」。

就像開會：
- 先抓關鍵詞（會議議程）
- 查舊資料（上次會議紀錄）
- 形成回覆（本次決策）
- 寫回紀錄（會議摘要）
- 訓練另存（演練筆記，不直接改正式制度）

## 本次已落地
1. 每輪關鍵字萃取（含語義 + 原句短語 +領域詞補強）
2. 每輪 Knowledge Hub 檢索
3. 回覆可帶關聯記憶摘要（非硬性，按結果注入）
4. 回寫互動圖譜資料：
   - `data/interaction_graph/turn_index.jsonl`
   - `data/interaction_graph/edges.jsonl`
5. 訓練分流資料（獨立於主流程）：
   - `data/training_overlay/dialog_turns.jsonl`

## 為什麼這樣比較穩
- 主流程仍是同一套服務與入口，不會被訓練噪音拖垮。
- 訓練樣本獨立存放，出問題可局部回滾，不影響中樞。
- 關係圖持續增長，對話不再是孤立點。

## 建議操作節奏
1. 先維持單一入口（5001）穩定。
2. 每天看 `interaction_graph` 是否正常增長。
3. 每週挑一批 `training_overlay` 做人工驗收後再合併規則。
