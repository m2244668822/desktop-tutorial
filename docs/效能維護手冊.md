# 🚀 高效能分層存儲維護手冊 (M1 Mac mini 優化版)

## 1. 系統架構概覽 (Architecture)

本系統採用 **Tiered Storage (分層存儲)** 策略，將運算壓力與儲存容量分離：

- **⚡️ 效能層 (SSD - `For Word`):** 存放頻繁讀寫的資料庫 (IOPS 密集型) 與 向量索引。
- **📚 容量層 (HDD - `智能體`):** 存放原始語意文本、筆記、備份 (容量密集型)。
- **🔗 橋接層 (Symlinks):** 透過 macOS 軟連結將兩者整合，對程式碼透明。

## 2. 關鍵路徑對照表 (Path Mapping)

| 數據類型         | 物理存放位置 (Physical)                                             | 系統連結路徑 (Logical/Symlink)                |
| :--------------- | :------------------------------------------------------------------ | :-------------------------------------------- |
| **對話資料庫**   | `/Volumes/For Word/Agent_FastData/instance/chat_history.db`         | `.sync_user_project/instance/chat_history.db` |
| **智能體記憶**   | `/Volumes/For Word/Agent_FastData/data/agent_memories`              | `data/agent_memories`                         |
| **語意索引表**   | `/Volumes/For Word/Agent_FastData/data/knowledge_hub/manifest.json` | `data/knowledge_hub/manifest.json`            |
| **原始語意內容** | `/Volumes/智能體/城城城程式/data_hdd_storage/notes_real`            | `data/knowledge_hub/notes` (軟連結)           |

## 3. 準則智能體執行守則 (Agent Rules)

**準則智能體 (Standard Agent) 在執行任務時，必須遵守以下指令：**

### 守則一：路徑完整性檢查

在啟動任何學習或讀取任務前，必須確認外接 SSD (`For Word`) 已正確掛載。

- **檢查指令:** `[ -L data ] && [ -L .sync_user_project/instance/chat_history.db ]`
- **異常處理:** 若連結斷開，禁止啟動後端，避免數據寫入內建 SSD 造成損耗。

### 守則二：數據分流寫入

- **禁止** 將超過 50MB 的非索引原始檔案存放在 `data/` 的非連結目錄下。
- **必須** 將所有新增的原始知識筆記放入 `data_hdd_storage/knowledge_hub/notes_real` (HDD)。

### 守則三：自動預索引維護

- **必須** 確保 `auto_pre_index.py` 在背景運行。
- 準則智能體應定期檢查 `/Volumes/For Word/Agent_FastData/logs/pre_index.log` 以確保 HDD 數據已成功同步至 SSD 索引。

## 4. 日常維護指令 (Maintenance)

### 啟動背景監控 (HDD -> SSD 同步器)

```bash
nohup python3 auto_pre_index.py > pre_index.log 2>&1 &
```

### 檢查磁碟健康與連結

```bash
ls -ld .sync_user_project/instance/chat_history.db data
```

### 數據備份與清理

- 舊數據備份於 `data_hdd_storage/`。
- 確認 SSD 運行穩定一週後，可清理 `.bak` 檔案。

## 5. 故障恢復 (Disaster Recovery)

若外接 SSD 故障或更換，請依序：

1. 從 HDD 的 `data_hdd_storage` 恢復數據。
2. 重新執行 `ln -s` 指令重建軟連結。
3. 執行 `agent_self_learning_upgraded.py` 重新生成向量索引至新 SSD。
