# 🤖 智能體核心系統升級文檔

## 📋 系統概述

本升級實現了三大核心系統的整合：

### 1️⃣ **對話學習提取系統** (Conversation Learning Extractor)

- **位置**: `learning/conversation_learning_extractor.py`
- **功能**: 從所有對話記憶中自動提取高價值知識

#### 核心能力

```
對話記憶 → 知識提取 → 優先級分類 → 訓練數據生成
```

#### 提取的知識類型

| 類型     | 優先級 | 用途             |
| -------- | ------ | ---------------- |
| 代碼示例 | 高     | 本地模型代碼生成 |
| 概念解釋 | 中     | 知識庫充實       |
| 最佳實踐 | 高     | 行為指導         |
| 常見錯誤 | 高     | 防止重複         |
| 性能優化 | 中     | 推理優化         |

#### 使用示例

```python
from conversation_learning_extractor import ConversationLearningExtractor

extractor = ConversationLearningExtractor(
    conversations_file="data/conversations.json"
)

# 提取所有知識
knowledge = extractor.extract_all_knowledge()

# 生成訓練數據
training_data = extractor.generate_training_data_for_local_model()

# 獲取摘要
summary = extractor.get_summary()
```

### 2️⃣ **增強型 RAG 神經索引系統** (Enhanced Neural Index)

- **位置**: `learning/enhanced_neural_index.py`
- **維度**: 768 維向量空間（可擴展到 1536）
- **神經連接**: 動態建立和優化

#### 核心特性

**多維向量嵌入**

- 768 維 embedding (默認) / 1536 維 (高精度)
- 支持中文和英文混合
- 餘弦相似度計算

**神經元叢集**

```
[文檔] → [神經元] → [連接圖] → [動態重排名]
```

**記憶增強檢索**

- 神經元激活歷史追蹤
- 重要性動態調整
- 質量度量加權

**自適應重排名**

```
Base Score = 相似度 (60%)
           + 激活歷史 (15%)
           + 重要性分數 (15%)
           + 連接密度 (10%)
```

#### 使用示例

```python
from enhanced_neural_index import EnhancedNeuralIndex

index = EnhancedNeuralIndex(dimensions=768)

# 添加文檔
neuron_id = index.add_document(
    doc_id="doc_001",
    content="Python 最佳實踐教程",
    metadata={"category": "tutorial"}
)

# 檢索
results = index.retrieve(
    query_embedding=query_vec,
    top_k=5,
    use_neural_reranking=True
)

# 優化索引
stats = index.optimize_index()
```

### 3️⃣ **本地模型自適應學習系統** (Adaptive Learning)

- **位置**: `learning/local_model_adaptive_learner.py`
- **學習來源**: 其他模型 (Gemini/Claude/OpenAI) 的對話
- **學習機制**: 反向學習 (Backward Learning)

#### 反向學習流程

```
Gemini/Claude 對話
    ↓
提取高質量知識
    ↓
分類優先級
    ↓
轉換為本地模型格式
    ↓
本地模型學習
    ↓
能力增強
```

#### 學習對象

| 類型     | 來源       | 優先級 |
| -------- | ---------- | ------ |
| 代碼範例 | 高品質回應 | 高     |
| 概念解釋 | 詳細答案   | 中     |
| 設計模式 | 架構討論   | 高     |
| 最佳實踐 | ✅ 標記    | 高     |
| 反面教材 | ❌ 標記    | 高     |

#### 使用示例

```python
from local_model_adaptive_learner import LocalModelAdaptivelearner

learner = LocalModelAdaptivelearner(
    training_data_file="data/learning/adaptive_training_data.json"
)

# 從對話中學習
learning_result = learner.learn_from_conversation(conversation)

# 應用學習到模型
apply_result = learner.apply_learning_to_model()

# 監控性能
performance = learner.monitor_performance()
```

#### 預期性能提升

- **準確度**: +5%
- **速度**: +2%
- **質量**: +8%

### 4️⃣ **接案與收益管理系統** (Task & Revenue Manager)

- **位置**: `business/task_and_revenue_manager.py`
- **目標市場**: 中文 AI 模型相關工作

#### 任務類型與收益預期

| 任務類型 | 預算範圍 | 時間    | 優先級 |
| -------- | -------- | ------- | ------ |
| 小型項目 | 5k-15k   | 40-80h  | 中     |
| 諮詢服務 | 2k-10k   | 20-50h  | 中     |
| 內容創建 | 1k-5k    | 15-30h  | 高     |
| 模型訓練 | 10k-50k  | 80-150h | 高     |
| 數據標註 | 500-5k   | 10-50h  | 低     |
| 優化工作 | 3k-20k   | 30-100h | 中     |

#### 接案工作流

```
機會檢測 → 可行性評估 → 容量檢查 → 自動接受/拒絕
                              ↓
                        任務分配 → 進度追蹤 → 完成驗收
                              ↓
                        收益記錄 → 發票生成 → 報表輸出
```

#### 容量管理

- **日工作容量**: 100% (可配置)
- **當前負荷**: 實時追蹤
- **任務自動調度**: 基於優先級和截止日期

#### 使用示例

```python
from task_and_revenue_manager import AgentTaskManager

manager = AgentTaskManager()

# 創建機會
opportunity = manager.create_opportunity(
    title="中文 BERT 模型優化",
    task_type="model_training",
    estimated_budget=25000,
    deadline="2026-04-01"
)

# 自動評估和接受
task = manager.evaluate_and_accept_task(opportunity["id"])

# 更新進度
manager.update_task_progress(task["id"], 50, "完成設計和開發")

# 生成報告
report = manager.generate_revenue_report(period_days=30)

# 獲取儀表板
dashboard = manager.get_dashboard()
```

#### 收益計算公式

```
淨收益 = 預算 × 70% - (預計時數 × 50 元/小時)
利潤率 = 淨收益 / 總收益 × 100%
```

## 📞 支援 & 故障排除

### 問題 1: 神經索引運行緩慢

**方案**: `index.optimize_index()` - 定期優化

### 問題 2: 學習效果不佳

**方案**: 增加對話數量，檢查 `adaptive_threshold`

### 問題 3: 任務接納率低

**方案**: 降低 `acceptable_task_min_revenue` 或提高工作容量

### 問題 4: 記憶不足

**方案**: 配置更高維度的向量 (1536D)，或清理舊神經元
