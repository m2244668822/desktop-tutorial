# 🖥️ 模型優化指南 - 8GB RAM Mac 配置

## 📊 您的系統配置

- **記憶體**: 8GB
- **CPU**: Dual-Core Intel Core i5 @ 1.6 GHz
- **已安裝模型**:
  - mistral: 4.4 GB (❌ 太重，不推薦)
  - llama3.2: 2.0 GB (⚠️ 會吃力)
  - phi: 1.5 GB (✅ **最優選擇**)

## 🎯 最佳模型推薦

### **第一選擇：Phi (1.5GB) ⭐⭐⭐⭐⭐**

```bash
ollama pull phi
```

**優點**:

- ✅ 輕量高效（1.5 GB）
- ✅ 高質量回應（微軟開發）
- ✅ 快速推理
- ✅ 適合您的8GB系統

**適用場景**:

- 日常對話和學習
- 文本生成和分析
- 知識問答

### **第二選擇：TinyLlama (0.6GB) ⭐⭐⭐⭐**

```bash
ollama pull tinyllama
```

**優點**:

- ✅ 超輕量（0.6 GB）
- ✅ 系統幾乎無負擔
- ✅ 極速回應

**缺點**:

- ⚠️ 回應質量一般
- ⚠️ 適合簡單任務

### **不推薦：Llama3.2 & Mistral**

- ❌ **llama3.2** (2.0 GB) - 會導致系統卡頓
- ❌ **mistral** (4.4 GB) - Mac會完全卡死

## 💡 常見問題

**Q: Phi 的質量如何？**  
A: Phi 是微軟開發的輕量模型，質量很好。完全足夠日常學習使用。

**Q: 可以同時運行多個模型嗎？**  
A: 不建議。8GB RAM 同時運行多個模型會導致系統卡頓。

**Q: 如果想要更強的模型怎麼辦？**  
A: 升級 RAM 到 16GB 或以上，才能流暢運行 llama3.2 或 mistral。
