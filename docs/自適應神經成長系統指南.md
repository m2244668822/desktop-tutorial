# 自適應神經成長系統使用指南

## 📋 概述

這是一個**漸進式自我升級系統**，讓智能體根據累積的數據自動調整神經網絡規模和連接強度。

**核心理念**：做中學 (Learning by Doing) - 系統會隨著使用逐步成長，而非一次性升級到最佳狀態。

---

## 🌱 自適應成長機制

### 成長階段

系統根據累積的對話數量，自動經歷以下成長階段：

| 階段       | 數據量門檻 | 神經元倍數 | 連接強度 | 特性     |
| ---------- | ---------- | ---------- | -------- | -------- |
| **初生期** | 0          | 1.0×       | 1.0×     | 基礎架構 |
| **學習期** | 500+       | 1.2×       | 1.1×     | 開始擴展 |
| **成長期** | 1000+      | 1.4×       | 1.2×     | 快速成長 |
| **發展期** | 1500+      | 1.6×       | 1.28×    | 持續優化 |
| **成熟期** | 2000+      | 1.8×       | 1.35×    | 穩定階段 |
| **進化期** | 3000+      | 2.0×       | 1.5×     | 進階能力 |

### 平滑過渡

- 系統在接近下一階段時（達到 80% 門檻），開始**預先成長**
- 避免突然的性能變化
- 確保用戶體驗平滑

### 活躍度調整

系統會根據最近的使用頻率微調成長參數：

- 高活躍度（頻繁使用）→ 加速成長 (+20%)
- 低活躍度（較少使用）→ 減緩成長 (-20%)

## 🔗 漸進式連接強化

### 連接追蹤

系統會自動追蹤：

- **哪些神經連接被頻繁激活**
- **激活的強度如何**
- **連接權重的歷史變化**

### 強化策略

**1. 頻繁使用的連接 → 逐步增強**

```
使用次數 ≥ 10次 → 開始強化
權重增長 = log(1 + 使用頻率) × 學習率
最大權重限制: 0.95
```

**2. 很少使用的連接 → 輕微衰減**

```
使用次數 < 5次 → 輕微衰減
權重衰減 = 0.001 × (1 - 使用頻率)
最小權重限制: 0.1
```

**3. 對數增長曲線**

- 避免權重過快增長
- 確保系統穩定性
- 保持學習能力

## 🚀 使用方法

### 1. 啟動聊天系統（自動啟用）

```bash
# 啟動 Groq 聊天（自適應成長已內建）
./start_groq_memory_chat.py

# 啟動 Gemini 聊天（自適應成長已內建）
./start_gemini_memory_chat.py
```

系統會自動：

- 根據數據量計算當前應處於的階段
- 自動調整神經元數量和連接強度
- 記錄成長事件到 `logs/neural_growth_log.json`

### 2. 查看成長狀態

```bash
# 完整的成長歷程查看
./view_neural_growth.sh

# 或直接運行
python3 tools/view_neural_growth.py
```

顯示內容：

- 成長時間軸（每次記錄的詳細信息）
- 成長統計（增長率、階段演進）
- 神經元數量趨勢圖（ASCII）
- 連接使用統計（最活躍的連接）

### 3. 執行漸進式維護

```bash
# 強化活躍連接
./maintain_neural_system.sh

# 僅查看狀態
./maintain_neural_system.sh --status
```

建議頻率：

- **每 100 個新對話後**運行一次
- 或**每週**運行一次

## 🔬 技術原理

### 為什麼要漸進式？

**傳統方式**（一次性升級）：

```
初始 → [一次性調整] → 最終狀態
問題: 可能不穩定、過度擬合、浪費資源
```

**漸進式方式**：

```
初始 → 適應 → 成長 → 優化 → 穩定 → 進化
優勢: 穩定、高效、符合實際需求
```

### 對數增長的優勢

使用 `log(1 + x)` 而非線性增長：

| 使用頻率 | 線性增長 | 對數增長 |
| -------- | -------- | -------- |
| 10%      | 0.010    | 0.004    |
| 50%      | 0.050    | 0.018    |
| 100%     | 0.100    | 0.030    |

對數增長：

- ✅ 避免過度強化
- ✅ 保持學習空間
- ✅ 更穩定可控

## 🆘 故障排除

### 問題：成長記錄為空

**原因**：尚未使用聊天系統

**解決**：

```bash
# 啟動任意聊天系統
./start_groq_memory_chat.py
# 進行一些對話後，系統會自動記錄
```

### 問題：連接強化無效

**原因**：激活追蹤未啟用

**解決**：

```bash
# 運行維護腳本
./maintain_neural_system.sh
```

### 問題：成長速度太慢/太快

**解決**：調整成長階段門檻（見「自定義配置」章節）
