# 中樞神經文件系統自主學習功能

## 🧠 概述

中樞神經系統現在具備**文件系統自主學習能力**，能夠：

- 🔍 自動掃描和監控整個項目的文件結構
- 🎯 智能分類文件（核心/配置/數據/測試/臨時等）
- 🧹 識別需要清理的廢物文件
- 📊 提供文件系統洞察和統計
- ⏰ 定期自動掃描（每30分鐘）

---

## ✨ 主要功能

### 1. 智能文件分類

系統自動將文件分為以下類別：

| 類別              | 描述         | 重要性 | 範例                                   |
| ----------------- | ------------ | ------ | -------------------------------------- |
| **core**          | 核心功能文件 | 10     | chat.py, agent.py, autonomous_agent.py |
| **config**        | 配置文件     | 9      | .env, config.json, constants.py        |
| **data**          | 數據文件     | 8      | conversations.json, learning_log.json  |
| **utility**       | 工具類文件   | 7      | utils.py, task_manager.py              |
| **documentation** | 文檔文件     | 6      | README.md, \*.txt                      |
| **test**          | 測試文件     | 3      | test**.py, *\_test.py, demo*\*.py      |
| **temporary**     | 臨時文件     | 1      | temp\__, backup._, record_this\*.py    |
| **cache**         | 緩存文件     | 0      | **pycache**, \*.pyc                    |

### 2. 自動清理建議

系統會識別以下類型的文件並提供清理建議：

✅ **測試文件** - 超過7天未修改的測試和演示文件  
✅ **臨時文件** - 臨時備份和記錄文件  
✅ **未使用文件** - 超過30天未訪問的低重要性文件  
✅ **緩存文件** - Python 緩存和編譯文件

### 3. 定期自動監控

中樞神經系統會：

- 🕐 每30分鐘自動掃描一次文件系統
- 📢 發現超過5個需清理文件時自動通知
- 📈 持續學習文件使用模式
- 💾 保存學習數據供未來分析

## 🚀 使用方法

### 方式 1: 交互式管理器（推薦）

```bash
python filesystem_manager.py
```

選項菜單：

1. 掃描文件系統
2. 深度掃描（分析文件內容）
3. 查看清理建議
4. 模擬清理
5. 執行清理（慎用！）
6. 查看文件系統洞察

### 方式 2: 命令行工具

```bash
# 掃描文件系統
cd 500/llama32-chat
python file_system_learner.py --scan

# 深度掃描（包括內容分析）
python file_system_learner.py --scan --deep

# 查看清理建議（模擬）
python file_system_learner.py --cleanup

# 實際執行清理
python file_system_learner.py --cleanup --force

# 查看洞察
python file_system_learner.py --insights
```

### 方式 3: Python API

```python
from autonomous_agent import autonomous_agent

# 手動掃描
results = autonomous_agent.perform_filesystem_scan(deep_scan=False)

# 獲取洞察
insights = autonomous_agent.get_filesystem_insights()

# 模擬清理
cleanup_result = autonomous_agent.auto_cleanup_filesystem(dry_run=True)

# 實際清理
cleanup_result = autonomous_agent.auto_cleanup_filesystem(dry_run=False)
```

## 💡 智能學習機制

### 文件重要性評分

系統根據以下因素評估文件重要性：

1. **文件類型** - 核心文件 > 配置 > 數據 > 工具 > 文檔 > 測試 > 臨時
2. **訪問頻率** - 經常訪問的文件重要性更高
3. **修改時間** - 最近修改的文件更可能是活躍的
4. **文件內容** - 深度掃描時分析代碼內容

### 學習數據

系統記錄每個文件的：

- 📁 路徑和名稱
- 📏 大小
- 🕐 創建/修改/訪問時間
- 🏷️ 分類和重要性
- 🔍 內容特徵（深度掃描）

## 🛡️ 安全機制

1. **模擬模式** - 默認只模擬，不實際刪除
2. **確認提示** - 實際清理前需要輸入 "yes" 確認
3. **重要文件保護** - 重要性 >= 5 的文件不會被建議清理

## 🐛 故障排除

### Q: 文件系統學習器未初始化

**A**: 確保在 `500/llama32-chat/` 目錄下運行，或檢查導入路徑

### Q: 掃描太慢

**A**:

- 使用普通掃描而非深度掃描
- 添加更多目錄到 `ignore_dirs`
- 減少掃描頻率

### Q: 不小心刪除了重要文件

**A**:

- 從 git 恢復：`git checkout -- <file>`
- 從備份恢復
- 下次使用前先執行模擬模式
