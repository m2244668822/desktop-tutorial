# 連續自主學習系統 - 使用指南

## 📌 功能概述

智能體現在可以**持續自動**與語言模型對話學習，自動提取並記錄三大優先主題的知識：

- 🧠 **精神疾病求生指南**（風險訊號 / 立即步驟 / 求助資源 / 每日自助）
- 🔬 **腦神經科學**（核心概念 / 可驗證問題 / 學習路徑 / 複習節奏）
- 📖 **聖經學習**（主題 / 核心信息 / 今日應用 / 禱告默想）

---

## 🚀 三種啟動方式

### 1️⃣ 啟動器選單（推薦）

```bash
python3 ai_agent_launcher.py
```

選擇 **6️⃣ 連續自主學習**，按提示選擇：

- **固定輪數模式**：設定學習輪數（例如 6 輪）
- **持續模式**：無限循環直到手動停止

### 2️⃣ 命令列模式

```bash
# 固定 6 輪，每輪間隔 1 秒
python3 autonomous_continuous_learning.py --rounds 6 --interval 1.0

# 持續模式，每輪間隔 2 秒
python3 autonomous_continuous_learning.py --continuous --interval 2.0
```

### 3️⃣ 背景常駐模式（一鍵啟動/停止）

```bash
# 啟動背景學習
./start_background_learning.sh

# 檢查運行狀態
./check_background_learning.sh

# 查看即時日誌
tail -f logs/autonomous_learning_background.log

# 停止背景學習（優雅關閉，自動保存）
./stop_background_learning.sh
```

---

## 📊 學習輪次說明

三大主題**輪流進行**，例如 6 輪的順序：

1. 精神疾病求生指南
2. 腦神經科學
3. 聖經學習
4. 精神疾病求生指南（深化）
5. 腦神經科學（深化）
6. 聖經學習（深化）

每輪會根據上一輪的回應內容，自動生成「延續追問」以深化學習。

---

## 💾 記錄與輸出

### 即時提取

- 每輪對話會**即時**使用專門模板提取重點
- 模板根據主題自動切換（求生指南 / 神經科學 / 聖經）

### 會話保存

- 所有對話 → `data/conversation_logs/groq_session_YYYYMMDD_HHMMSS.json`
- 包含 `conversation_history` 和 `learning_extractions`

### 自主學習分析

- 每次會話結束自動執行反思
- 識別主題、計算統計、提出改進方向
- 記錄寫入 `logs/agent_learning_log.jsonl`

## ⚙️ 參數調整

### 修改學習間隔

```bash
# 快速測試（0.5 秒間隔）
--interval 0.5

# 生產環境（3 秒間隔，降低 API 壓力）
--interval 3.0
```

### 修改學習提示詞

編輯 [`autonomous_continuous_learning.py`](autonomous_continuous_learning.py) 中的 `LEARNING_TRACKS` 常數：

```python
LEARNING_TRACKS = [
    {
        "name": "精神疾病求生指南",
        "prompt": "你的自訂提示詞..."
    },
    ...
]
```

## 🔍 監控與除錯

### 檢查背景狀態

```bash
./check_background_learning.sh
```

顯示：PID、運行時間、記憶體用量、最近 10 行日誌

### 查看完整日誌

```bash
# 即時追蹤
tail -f logs/autonomous_learning_background.log

# 搜尋特定主題
grep "精神疾病" logs/autonomous_learning_background.log

# 統計完成輪數
grep "第.*輪" logs/autonomous_learning_background.log | wc -l
```

### 手動停止進程

如果停止腳本失敗，手動終止：

```bash
# 查找 PID
ps aux | grep autonomous_continuous_learning

# 優雅停止（先嘗試）
kill -INT <PID>

# 強制終止（最後手段）
kill -9 <PID>

# 清理 PID 文件
rm -f .autonomous_learning.pid
```

## 🎯 最佳實踐

### 1. 短測試 → 長運行

先用固定輪數（2-3 輪）測試配置，確認無誤後再啟用持續模式或長輪數。

### 2. 監控 API 配額

Groq 免費帳號有**每日請求限制**，建議：

- 設定間隔 ≥ 2 秒
- 定期檢查 API 用量（`config/api_usage.json`）
- 避免同時運行多個學習進程

### 3. 定期清理日誌

背景模式會持續寫入日誌，建議每週清理：

```bash
# 備份後清空
cp logs/autonomous_learning_background.log logs/backup_$(date +%Y%m%d).log
> logs/autonomous_learning_background.log
```

### 4. 結合啟動器使用

- 選項 1：互動對話
- 選項 5：執行自主學習分析
- 選項 6：連續自主學習

交替使用以平衡「人機對話」與「機器自學」。

## ❓ 常見問題

**Q: 背景模式會不會一直跑到沒電？**  
A: 會，除非手動停止或設定 cron 定時停止。建議搭配電源管理使用。

**Q: 可以同時運行多個學習進程嗎？**  
A: 技術上可行，但會：① 快速消耗 API 配額 ② 產生多個會話檔案 ③ 記憶體用量增加。不建議。

**Q: 學習記錄太多會不會影響效能？**  
A: 會話檔案會累積，建議每月歸檔舊記錄到 `data/conversation_logs/archive/`。

**Q: 如何整合到現有工作流程？**  
A: 結合 `ai_agent_launcher.py` 使用，或設定 Alfred/Raycast 快捷鍵直接呼叫背景腳本。
