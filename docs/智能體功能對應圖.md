## 2) 功能 → 模組對應

| 功能           | 主要模組                                                         | 用途                                   |
| -------------- | ---------------------------------------------------------------- | -------------------------------------- |
| API 與任務管理 | `flask`, `flask-sqlalchemy`, `flask-limiter`                     | 提供路由、資料庫、流量限制             |
| 智能體編排     | `langgraph`, `langchain`                                         | 多步驟流程與工具串接                   |
| 多智能體協作   | `autogen-agentchat`, `autogen-ext`                               | agent 分工與協作回報                   |
| 語意比對/RAG   | `sentence-transformers`, `faiss-cpu`, `chromadb`, `transformers` | 向量化、相似度比對、檢索增強           |
| 實境面板可視化 | `cursor-agent-sidebar-extension`（webview + sidebar.js）         | 馬賽克角色、任務狀態燈、語言監控卡片   |
| 終端同步回覆   | `VS Code Terminal API` + `postTerminalLog`                       | 側欄回覆同步輸出到「智能體回覆終端機」 |
| API 通訊與韌性 | `httpx`, `requests`, `tenacity`, `pydantic`                      | 呼叫外部服務、重試、資料驗證           |
| 本地模型接入   | `ollama`                                                         | 連接本地 LLM                           |
| JSON/效能      | `orjson`                                                         | 快速序列化與大資料處理                 |
| 桌面 UI        | `pywebview`, `pyobjc-core`, `pyobjc-framework-Cocoa`             | 桌面面板與原生介面                     |
