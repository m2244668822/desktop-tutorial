# 領域關鍵字與橋接邏輯地圖

## 1. 優先主題 (Priority Topics)

| 主題             | 核心關鍵字                               | 權重 | 建議深度 |
| :--------------- | :--------------------------------------- | :--- | :------- |
| **精神健康求生** | 創傷、解離、焦慮、憂鬱、自傷、心理危機   | 1.5x | 3 輪     |
| **腦神經科學**   | 神經元、突觸、神經可塑性、神經遞質、腦區 | 1.3x | 3 輪     |
| **聖經學習**     | 經文、福音、詩篇、救恩、禱告、信仰       | 1.2x | 2 輪     |

## 2. 知識橋接地圖 (Knowledge Bridges)

- **神經科學 ⟷ 精神健康**：
  - 核心：神經生物學視角的精神疾病。
  - 關鍵：為什麼創傷會改變大腦？神經可塑性如何支持恢復？
- **信仰 ⟷ 精神健康**：
  - 核心：精神信仰與心理韌性。
  - 關鍵：聖經教導如何幫助應對精神危機？信仰如何作為求生工具？
- **神經科學 ⟷ 信仰**：
  - 核心：神經科學與靈性體驗。
  - 關鍵：冥想與祈禱對大腦的神經影響。

## 3. 深化追問範例 (Deep Follow-up)

- 「這個概念與你之前學到的知識有什麼連結？」
- 「在實施這些求生步驟時，可能遇到哪些具體挑戰？」
- 「聖經中的這段經文在歷史文脈中的原始意義是什麼？」
