## 🎯 常見任務

### 任務 1: 記錄一個對話

**方式 A: 自動記錄 (推薦)**

```bash
python chat_client.py
# 每個對話都會自動記錄
```

**方式 B: 手動 API 調用**

```python
from autonomous_agent import autonomous_agent

autonomous_agent.record_conversation_session(
    user_message="用戶的消息",
    ai_response="AI 的回應",
    context={"source": "manual"}
)
```

### 任務 2: 檢查驗證狀態

```python
from autonomous_agent import autonomous_agent

status = autonomous_agent.get_session_verification_status()

print(f"✅ 已驗證: {status['verified_sessions']} 個")
print(f"⏳ 待驗證: {status['unverified_sessions']} 個")
print(f"📈 驗證率: {status['verification_rate']}")
print(f"⏰ 最後驗證: {status['last_verification']}")
```

### 任務 3: 查看廢棄文件

**方式 A: 互動式工具**

```bash
python session_data_manager_tool.py
# 選擇選項 2: 查看清理建議
# 或選擇選項 3: 預覽清理 (Dry-Run)
```

**方式 B: 直接 API**

```python
from autonomous_agent import autonomous_agent

recommendations = autonomous_agent.get_cleanup_recommendations()
for folder, data in recommendations['recommendations_by_folder'].items():
    print(f"{folder}: {data['trash_count']} 個廢棄文件")
```

### 任務 4: 執行清理 (謹慎!)

**步驟 1: 先預覽 (推薦)**

```python
from autonomous_agent import autonomous_agent

result = autonomous_agent.analyze_and_cleanup_trash(dry_run=True)
print(result['cleanup_summary'])
```

**步驟 2: 確認無誤後執行**

```python
from autonomous_agent import autonomous_agent

result = autonomous_agent.analyze_and_cleanup_trash(dry_run=False)
print(f"已刪除 {result['files_deleted']} 個文件")
print(f"釋放空間: {result['total_space_freed'] / 1024:.2f} KB")
```

### 任務 5: 查看完整報告

```python
from autonomous_agent import autonomous_agent

report = autonomous_agent.generate_data_management_report()
print(report)
```

## 🐛 常見問題解決

### Q: 為什麼新記錄還沒驗證？

**A:** 新記錄需要 10 分鐘後自動驗證。檢查 `verification_report.json` 查看驗證進度。

### Q: 如何加快驗證速度？

**A:** 不推薦。10 分鐘週期確保系統穩定。但可以修改 `session_data_manager.py` 中的 `VERIFICATION_INTERVAL = 600` 參數。

### Q: Dry-Run 預覽沒有顯示任何文件？

**A:** 可能沒有廢棄文件，或者所有廢棄文件都被白名單保護了。正常現象。

### Q: 如何確認清理確實執行了？

**A:** 檢查 `cleanup_log.json` 文件，查看 `deleted_files` 列表。

### Q: 誤刪了文件怎麼辦？

**A:** 使用系統回收站或時間簽名恢復。建議定期備份。

## 🔄 工作流程示例

### 完整工作流程

```
1. 啟動聊天應用
   └─> chat_client.py 自動初始化 SessionDataManager

2. 進行對話
   └─> 每個對話自動記錄到 session_tracking.json

3. 等待 10 分鐘
   └─> 背景驗證線程自動驗證記錄

4. 檢查系統狀態
   python session_data_manager_tool.py
   └─> 選擇 5 查看完整報告

5. 清理廢棄文件 (可選)
   python session_data_manager_tool.py
   └─> 選擇 2 查看廢棄文件
   └─> 選擇 3 預覽清理內容
   └─> 選擇 4 執行清理 (確認後)

6. 驗證清理結果
   └─> 檢查 cleanup_log.json
```
