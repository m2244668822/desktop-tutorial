## 第二部分：RAG 神經索引優化

### 目標

建立高效的檢索增強生成系統，提升回答質量

### 步驟 1: 初始化神經索引

```python
from learning.enhanced_neural_index import EnhancedNeuralIndex

# 創建 768 維索引（高效+ 精確）
index = EnhancedNeuralIndex(
    index_dir="data/neural_index",
    dimensions=768
)

print(f"✅ 神經索引已建立")
print(f"   維度: {index.dimensions}")
print(f"   當前神經元: {len(index.neurons)}")
```

### 步驟 2: 導入知識到索引

```python
import json

# 讀取提取的知識
with open("data/learning/extracted_knowledge.json") as f:
    knowledge = json.load(f)

# 逐個添加到索引
for know in knowledge['knowledge_extracted']:
    doc_id = know['conversation_id']
    content = json.dumps(know['knowledge_items'], ensure_ascii=False)

    neuron_id = index.add_document(doc_id, content)
    print(f"✅ 添加神經元: {neuron_id}")

print(f"📊 索引統計:")
print(f"   總神經元: {len(index.neurons)}")
print(f"   總連接: {len([c for ns in index.neural_graph.values() for c in ns])}")
```

### 步驟 3: 配置檢索參數

```python
# 添加高優先級知識，提高重要性
for neuron_id, neuron in list(index.neurons.items())[:100]:
    if neuron['metadata'].get('priority') == 'critical':
        index.update_neuron_importance(neuron_id, 0.9)
    elif neuron['metadata'].get('priority') == 'high':
        index.update_neuron_importance(neuron_id, 0.7)

print("✅ 重要性評分已更新")
```

### 步驟 4: 優化索引性能

```python
# 優化索引
optimized_stats = index.optimize_index()

print(f"📈 優化完成:")
print(f"   神經元: {optimized_stats['total_neurons']}")
print(f"   連接: {optimized_stats['total_connections']}")
print(f"   平均激活: {optimized_stats['average_activation']:.2f}")

# 保存索引
index.save_index()
print("💾 索引已保存")
```

### 步驟 5: 測試檢索效果

```python
# 生成查詢向量
test_queries = [
    "Python 最佳實踐",
    "本地模型優化",
    "代碼示例"
]

for query in test_queries:
    query_vec = index._generate_pseudo_embedding(query)
    results = index.retrieve(query_vec, top_k=3)

    print(f"\n🔍 查詢: {query}")
    for i, result in enumerate(results, 1):
        print(f"   {i}. {result['doc_id']} (相似度: {result['similarity']:.3f})")
```

## 故障排除

### 問題 1: 神經索引增長過快

**症狀**: 內存占用不斷增加
**解決**:

```python
# 清理低活躍度神經元
index.optimize_index()

# 或者減少新文檔添加
index.max_neurons = 5000
```

### 問題 2: 本地模型質量沒有改進

**症狀**: 經過學習後，模型效果沒有變化
**解決**:

```python
# 檢查數據質量
summary = extractor.get_summary()

# 增加學習率
learner.learning_rate = 0.02

# 重新運行學習週期
learner.monitor_performance()
```

### 問題 3: 接案率過低

**症狀**: 無法接受足夠的任務
**解決**:

```python

manager.acceptable_task_min_revenue = 300

# 增加工作容量
manager.work_capacity = 120

# 擴展任務類型
```

### 問題 4: 利潤率下降

**症狀**: 最近項目利潤率低於預期
**解決**:

