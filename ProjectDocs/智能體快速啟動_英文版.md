# 🎯 智能體快速啟動指南

## 30 秒快速啟動

```bash
# 1. 進入目錄
cd /Volumes/智能體/城城城程式/500/llama32-chat

# 2. 啟動 Ollama
ollama serve &

# 3. 在新終端運行集成系統
python3 core/agent_core_integration.py

# ✅ 系統啟動完成！
```

## 核心功能速查

| 功能       | 代碼                                   | 結果         |
| ---------- | -------------------------------------- | ------------ |
| 提取知識   | `extractor.extract_all_knowledge()`    | 自動分析對話 |
| 更新索引   | `index.optimize_index()`               | 提升檢索速度 |
| 應用學習   | `learner.apply_learning_to_model()`    | 改進本地模型 |
| 接受任務   | `manager.evaluate_and_accept_task(id)` | 自動接案     |
| 查看儀表板 | `system.get_system_dashboard()`        | 系統狀態     |

## 一分鐘配置

```python
# 複製以下代碼到 Python 交互式環境

from core.agent_core_integration import AgentCoreIntegration

# 初始化
system = AgentCoreIntegration()

# 配置參數
system.task_manager.acceptable_task_min_revenue = 500
system.task_manager.work_capacity = 100

# 查看狀態
print(system.get_system_dashboard())

# ✅ 系統已配置
```
