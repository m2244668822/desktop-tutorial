# AI 聊天工具使用指南

## 📁 主要文件

### 1. **easy_chat.py** ⭐ 推薦使用

最簡單的聊天工具，無緩存問題。

**使用方法：**

```bash
# 1. 編輯 message.txt 輸入你的問題
# 2. 執行
python easy_chat.py
```

### 2. **chat_client.py** - 完整智能系統

具備記憶、智能切換、多 API 支持等功能。

**功能：**

- 🧠 對話記憶（儲存在 chat_memory.json）
- 🔄 智能 API 切換
- 🔍 自動偵測可用服務
- 📊 使用追蹤

**使用方法：**

```bash
python chat_client.py
```

### 3. **message.txt** - 訊息輸入文件

在編輯器中修改此文件來輸入問題（避免終端機中文輸入問題）

---

## 🧹 清理測試數據

**快速清理：**

```bash
python clean_test.py
```

**手動清理：**

```bash
# 刪除測試文件
rm -f test_*.py *.bak*

# 清理記憶（會自動備份）
rm chat_memory.json

# 清理 Python 緩存
find . -name "__pycache__" -exec rm -rf {} +
find . -name "*.pyc" -delete
```

---

## 📝 最佳實踐

1. **日常使用** → 用 `easy_chat.py`
2. **需要記憶** → 用 `chat_client.py`
3. **定期清理** → 運行 `python clean_test.py`
4. **測試完成後** → 立即刪除測試文件和數據
