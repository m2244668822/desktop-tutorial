## 🎯 **問題根源分析 - 事後學習**

### 原因回顧

```
1️⃣ 根本原因
   Phi 模型 (1.6GB) 在 8GB RAM 系統上運行
   → 需要完整加載到內存
   → 推理過程中內存持續增長
   → 達到上限

2️⃣ 激化因素
   macOS 壓縮緩存未及時回收 (2090MB 卡住)
   → 系統無 swap 回收機制
   → 後台服務也在爭奪內存

3️⃣ 最終結果
   可用內存: 18MB → 系統服務無法運行
   Ollama API: 無法推理 → 完全崩潰
```

### 為何重啟有效

```
重啟清理步驟:
1. 終止所有用戶進程 ✅
2. 清空應用內存 ✅
3. 回收系統緩存 ✅ (872MB 壓縮緩存)
4. 重新初始化 Ollama ✅
5. 內存恢復到穩定狀態 ✅ (98.3%)
```
